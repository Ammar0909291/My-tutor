## Learning Objective

The learner can: state that two fractions a/b and c/d are equivalent
exactly when a×d=b×c (cross-multiplication); generate equivalent
fractions by multiplying (never adding) numerator and denominator by
the same nonzero integer; verify equivalence between two given
fractions using cross-multiplication; and explain WHY multiplying both
parts by the same k preserves value (multiplying by k/k=1), not merely
execute the procedure mechanically.

## Core Understanding

`math.arith.fractions` already establishes fraction notation and the
numerator/denominator meaning. Two fractions a/b and c/d are
**equivalent** — name the SAME quantity — exactly when a×d=b×c
(cross-multiplication test). Equivalence is generated multiplicatively:
multiplying (or dividing) both numerator and denominator by the same
nonzero integer k produces a fraction naming the identical value,
because a/b×(k/k)=(ak)/(bk), and k/k=1 for any nonzero k — multiplying
by 1 never changes a value. Every rational number is therefore an
EQUIVALENCE CLASS of infinitely many fraction representations
(1/2=2/4=3/6=…=n/(2n) for all nonzero n); the CANONICAL (reduced) form,
where GCD(|numerator|,denominator)=1, is one chosen representative, not
the exclusively "real" one. This is a purely MULTIPLICATIVE
relationship — critically NOT additive: adding the same number to both
numerator and denominator does NOT preserve value (1/3≠2/4, since
1÷3≈0.333 while 2÷4=0.5).

## Mental Models

- **Beginner model — "1/2 and 2/4 are different fractions that happen
  to look related"**: the learner treats the fraction SYMBOL as the
  identity of the number, so visually distinct fractions feel like
  distinct objects. Shelf-life warning: this model rejects
  simplification as "changing the number" and cannot accept a
  non-reduced fraction as a legitimate answer.
- **Intermediate model — "equivalent fractions are generated by
  multiplying numerator and denominator by the same integer, verified
  by cross-multiplication"**: the learner correctly generates and
  verifies equivalents mechanically, but may not yet articulate WHY the
  value is preserved, or may believe only the reduced form is truly
  valid. Upgrade trigger: being asked whether a non-simplified fraction
  like 6/8 is "still a real fraction."
- **Advanced model — "a/b×(k/k)=a/b×1=a/b — multiplying by k/k IS
  multiplying by 1, which is why the value never changes; canonical
  form is a chosen representative of an infinite equivalence class,
  never the exclusively valid form"**: the learner fluently explains
  the k/k=1 mechanism and treats every valid representation as equally
  legitimate. Upgrade trigger: being asked to explain, without
  reference to any specific numbers, why multiplying top and bottom by
  the same nonzero integer never changes a fraction's value.
- **Do not upgrade early**: a learner still treating differently-named
  equivalent fractions as different numbers (beginner model, directly
  triggering MC-1's additive-thinking risk) should not be pushed toward
  the k/k=1 proof (advanced model) before the multiplicative generation
  rule itself is secure.

## Why Students Fail

The dominant failure generalizes the symmetric "same operation to both
sides" heuristic from equation-solving onto fractions, producing
equivalents by ADDING the same number to numerator and denominator
(e.g., 1/3→2/4) — a genuine error, since addition changes the ratio
while multiplication scales both parts proportionally together. A
second failure, instilled by school instruction's constant "always
simplify your answer" emphasis, treats the reduced form as the ONLY
legitimate fraction for a given value, rejecting non-simplified
equivalents like 6/8 as "not a proper fraction" or "a different
fraction" rather than an equally valid alternate name.

## Misconceptions

Reusing the Blueprint's Misconception Registry (Educational Brain v1.0
format — Student State Matrix S0-S9, Diagnostic Battery DB-1-DB-3,
Protocols A-E), birth-type classification added per this program's
diagnostic procedure — not re-derived:

### MC-1: ADDING-PRESERVES-EQUIVALENCE (Foundational; Type 1 — overgeneralization)
**Trigger** (Blueprint DB-2): asked to make a fraction equivalent to
1/3 by multiplying, then asked whether 4/6 is equivalent to 3/5, the
learner produces 2/4 from 1/3 by adding 1 to numerator and denominator.
**Root cause** (Blueprint's own): the "same operation to both sides"
symmetry heuristic, correctly learned from equation-solving, is
over-generalized to fractions, conflating addition and multiplication
as equally valid symmetric operations.
**Repair**: as decimals, 1÷3≈0.333 while 2÷4=0.500 — genuinely
different values; the "add 1" rule produces a DIFFERENT fraction, not
an equivalent one. Multiplying by k scales both numerator and
denominator PROPORTIONALLY together — the ratio (numerator÷denominator)
stays fixed because both scale by the identical factor.
**MAMR**: FOUNDATIONAL for MC-2 — must be cleared first, since MC-2's
repair involves cross-multiplication verification on non-simplified
fractions, incoherent if the learner is still generating wrong
"equivalents" via addition.

### MC-2: ONLY-SIMPLIFIED-IS-VALID (Moderate; Type 1 — overgeneralization)
**Trigger** (Blueprint): asked whether 6/8 is equivalent to 3/4, the
learner rejects 6/8 as "not a proper fraction" or "a different
fraction" since it isn't in lowest terms.
**Root cause** (Blueprint's own): school instruction's "always simplify
your answer" is over-interpreted as "the simplified form IS the
fraction; every other form is incorrect or inferior."
**Repair**: cross-multiplication confirms 3×8=24=4×6, so 6/8 and 3/4
name the SAME point on the number line — equivalent fractions are
multiple names for one quantity; simplification finds the simplest
name, but every name for the same value is equally valid and equally
equivalent.

## Analogies

**Primary — many names for one person (Blueprint's own analogy, via
its P64 conceptual-shift language)**: a rational number is not a
fraction symbol — it is a specific position on the number line, and
p/q is notation POINTING to that position, just as "Wolfgang Amadeus
Mozart" and "Mozart" are two names for the same person. 1/2 and 2/4
point to exactly the same position: halfway between 0 and 1. Canonical
(reduced) form is the official name; other forms are equally valid
aliases, never lesser ones.

**Anti-analogy to retire**: "A fraction and its simplified form are
technically different numbers that happen to be equal, like two
different people who look the same." This directly invites MC-2 by
suggesting equivalence is a coincidental external relationship between
genuinely distinct objects, rather than two names for the exact same
single object.

## Demonstrations

**Cross-multiplication verification**: is 12/18 equivalent to 8/12?
12×12=144=18×8 — equal, so YES. Reduce both: GCD(12,18)=6→2/3;
GCD(8,12)=4→2/3 — same canonical form confirms the same equivalence
class.

**MC-1's additive-vs-multiplicative contrast**: 1/2=2/4=3/6=n/(2n) for
all nonzero n, all generated by MULTIPLICATION; adding 1 to 1/2's parts
gives 2/3, a genuinely different value (1/2=0.5≠2/3≈0.667).

**MC-2's simplification-is-not-exclusivity contrast**: 10/15 and 2/3
are BOTH valid fractions and equivalent (10×3=30=15×2) — 10/15 being
unreduced does not make it invalid or "a different fraction."

## Discovery Questions

Present the strip-folding activity from the Blueprint's own TA-A01/A02
sequence: fold a paper strip in half (shade 1/2), then refold into
quarters (2/4 shaded) — the learner discovers the shaded LENGTH is
identical despite the different fraction names, directly experiencing
equivalence before cross-multiplication is introduced formally.
Recommendation: guided discovery for the equal-shaded-length insight
(directly experiential from physical folding); direct instruction for
the cross-multiplication test and the k/k=1 mechanism (MC-1's repair),
since the algebraic justification is not independently rediscoverable
from folding alone.

## Teaching Sequence

MC-1 (adding preserves equivalence) is addressed first and is
FOUNDATIONAL per the Blueprint's own MAMR — it must be cleared before
MC-2, since MC-2's repair (verifying non-simplified fractions via
cross-multiplication) is incoherent if the learner is still generating
incorrect "equivalents" via addition. MC-2 (only-simplified-is-valid)
is addressed second, once the multiplicative generation rule is secure.

## Voice Teaching Notes

**Register**: Say "multiply, never add" explicitly whenever
introducing equivalent-fraction generation, since the symmetry
heuristic from equation-solving is exactly what MC-1 exploits.

**Wait-time**: After presenting the cross-multiplication test on a
non-obvious pair (e.g., 4/6 vs 3/5), give extended wait-time before
revealing the verdict — let the learner compute both products
themselves.

**Load-bearing sentences**:
- "Multiplying top and bottom by the same number is multiplying by
  k/k, which is multiplying by 1 — the value can never change."
- "A fraction doesn't have to be simplified to be valid — 6/8 and 3/4
  are equally correct names for the same number."

## Tutor Recovery Strategy

Likeliest utterance: "how can 1/2 and 2/4 be the SAME thing — they
don't even look alike?" — the concept-specific smaller question: "if
you cut a pizza into 2 equal slices and take 1, versus cutting it into
4 equal slices and taking 2, do you end up with the same amount of
pizza?" reframes the confusion from "different symbols mean different
numbers" (MC-1's symbol-as-identity root) to "different symbols can
point to the same quantity," directly isolating MC-1 with a concrete,
directly comparable physical instance.
