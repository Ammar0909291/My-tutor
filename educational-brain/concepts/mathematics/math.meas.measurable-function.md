## Learning Objective
Define $f:(X,\mathcal F)\to(Y,\mathcal G)$ as MEASURABLE iff $f^{-1}(E)\in\mathcal F$ for EVERY
$E\in\mathcal G$ — directly paralleling the topological "preimages of open sets are open"
definition of continuity, with "measurable" replacing "open"; state the practical BOREL TEST
(checking preimages of open intervals suffices, since they generate the Borel σ-algebra); and
recognize that measurability is STRICTLY WEAKER than continuity — every continuous function is
measurable, but a measurable function need not be continuous.

## Core Understanding
MEASURABILITY IS THE CONTINUITY DEFINITION, GENERALIZED FROM "OPEN" TO "MEASURABLE": $f$ is
measurable iff $f^{-1}(E)\in\mathcal F$ for every $E\in\mathcal G$ — the preimage of every
measurable target set lands as a measurable source set. For $X=\{1,2,3,4\}$ with
$\mathcal F=\{\emptyset,\{1,2\},\{3,4\},X\}$ and $f(1)=f(2)=0$, $f(3)=f(4)=1$: checking
$E=(-1,0.5)$ gives $f^{-1}(E)=\{1,2\}\in\mathcal F$; checking $E=(0.5,1.5)$ gives
$f^{-1}(E)=\{3,4\}\in\mathcal F$ — both land correctly, confirming measurability directly.

CHECKING OPEN INTERVALS ALONE SUFFICES FOR THE FULL BOREL TEST — A GENUINE SHORTCUT, NEVER AN
APPROXIMATION: since the Borel σ-algebra is GENERATED by open sets, and preimage-taking respects
σ-algebra operations (unions, complements), verifying $f^{-1}(E)$ measurable for every open
interval $E$ automatically extends to EVERY Borel set — no need to check uncountably many sets
individually. For $f(x)=x^2$: $f^{-1}((a,b))=(-\sqrt b,-\sqrt a)\cup(\sqrt a,\sqrt b)$ for
$0<a<b$, a union of open intervals, itself measurable — this pattern holding for every open
interval confirms full Borel measurability via the generating-set shortcut alone.

MEASURABLE IS STRICTLY WEAKER THAN CONTINUOUS — CONTINUOUS IMPLIES MEASURABLE, NEVER THE
CONVERSE: every continuous $f:\mathbb R\to\mathbb R$ is automatically Borel measurable, since
continuity means $f^{-1}(U)$ is open (hence measurable) for every open $U$. But the STEP FUNCTION
$g(x)=0$ for $x<0$, $g(x)=1$ for $x\ge0$ is measurable ($g^{-1}((-0.5,0.5))=(-\infty,0)$ open;
$g^{-1}((0.5,1.5))=[0,\infty)$ closed, hence still measurable) DESPITE having a genuine jump
discontinuity at $x=0$ — proving measurability is a strictly LARGER, more permissive class than
continuity, never equivalent to it.

## Mental Models
- **"Measurability is continuity's own definition, generalized — swap 'open' for 'measurable'
  everywhere, and the same preimage logic carries through unchanged."**
- **"Checking the generating open intervals is enough — the σ-algebra structure propagates the
  check automatically to every Borel set, a genuine shortcut, not a partial verification."**

## Why Students Fail

### MC-1: MEASURABLE-ASSUMED-EQUIVALENT-TO-CONTINUOUS
- **Surface form**: believes measurability and continuity are equivalent conditions, rather than
  recognizing measurability as strictly weaker.
- **Birth type**: Type 1, overgeneralization (Blueprint's own declared Foundational severity —
  "continuous implies measurable" is the fact most commonly stated in passing, creating a natural
  but incorrect assumption of equivalence).
- **Repair**: re-walk the step-function example explicitly, showing a genuinely discontinuous
  function passing the measurability test cleanly.

### MC-2: ALL-BOREL-SETS-ASSUMED-TO-REQUIRE-INDIVIDUAL-CHECKING
- **Surface form**: believes verifying measurability requires checking the preimage of every
  individual Borel set, rather than recognizing a generating collection suffices.
- **Birth type**: Type 5, instruction-induced (Blueprint's own declared Moderate severity — the
  formal definition quantifies over "every $E\in\mathcal G$," which reads as requiring exhaustive
  individual checking before the generating-set shortcut is introduced).
- **Repair**: re-anchor on the generating-set principle — checking open intervals alone suffices,
  since the σ-algebra structure propagates automatically.

### MC-3: MEASURABILITY-DEFINITION-DIRECTION-REVERSED
- **Surface form**: states the measurability condition backwards — checking $f(A)\in\mathcal G$
  for $A\in\mathcal F$ (forward image) rather than the correct $f^{-1}(E)\in\mathcal F$ for
  $E\in\mathcal G$ (preimage).
- **Birth type**: Type 4, notation-induced (Blueprint's own declared Moderate severity — forward
  image notation $f(A)$ is visually simpler and more intuitive than preimage notation $f^{-1}(E)$,
  inviting the reversal).
- **Repair**: re-derive by direct analogy with the continuity definition — preimages, never
  forward images, which need not behave well at all.

## Analogies
- **"Measurability is continuity's passport check, generalized to a country with different
  borders — the same 'preimage lands inside' rule, just applied to measurable sets instead of
  open ones."**
- **Anti-analogy**: measurable does NOT mean continuous — a function can jump discontinuously and
  still be perfectly measurable, as the step function shows directly.

## Demonstrations
- **Demonstration 1 (targets MC-3)**: the finite-space function $f$ on $X=\{1,2,3,4\}$: verifying
  $f^{-1}(E)\in\mathcal F$ for target sets $E$, never checking $f(A)$ for source sets $A$.
- **Demonstration 2 (targets MC-2)**: $f(x)=x^2$'s open-interval-by-open-interval check, showing
  the generating-set shortcut confirms full Borel measurability without checking non-interval
  Borel sets.
- **Demonstration 3 (targets MC-1)**: the step function $g$ is measurable (preimages of open
  intervals are always open, closed, empty, or all of $\mathbb R$ — all measurable) despite a
  genuine jump discontinuity at $x=0$.

## Discovery Questions
1. "Since every continuous function is measurable, does that mean every measurable function must
   also be continuous?"
2. "Does verifying measurability require checking every individual Borel set, or is there a
   shortcut?"
3. "Is the measurability condition $f^{-1}(E)\in\mathcal F$, or is it $f(A)\in\mathcal G$?"

## Teaching Sequence
1. **Representation shift**: state the measurability definition by direct analogy with continuity,
   working Demonstration 1's finite-space verification, isolating MC-3 by requiring the preimage
   direction stated correctly.
2. **Conceptual shift/conflict evidence**: Demonstration 2's open-interval sufficiency test,
   isolating MC-2 by requiring the generating-set shortcut applied rather than exhaustive
   checking.
3. **Contrast pair**: Demonstration 3's measurable-but-discontinuous step function, isolating MC-1
   by requiring the one-directional implication (continuous ⇒ measurable) stated precisely.
4. **Mastery gate**: require a correct measurability verification for a new function via the
   open-interval test, a correct explanation of why continuous implies measurable but not
   conversely, and a correct preimage-direction statement of the definition, at the Blueprint's
   own stated MAMR of 5/5 (⌈0.85×5⌉).

## Tutor Actions
- Never accept "measurable" and "continuous" treated as equivalent conditions.
- Never accept the measurability condition stated with forward images instead of preimages.

## Voice Teaching Notes
- Say "is that function measurable because it's continuous, or could it be measurable even if it
  jumps?" whenever measurability and continuity are compared.
- When the definition is stated, ask "is that a preimage condition, or did that switch to forward
  images?"

## Assessment Signals
- **Rung 1 (recognition)**: learner correctly verifies measurability for a new function using the
  preimage definition.
- **Rung 2 (application)**: learner correctly applies the open-interval sufficiency test to a new
  Borel-measurability check.
- **Rung 3 (transfer)**: learner correctly identifies a new discontinuous function as measurable,
  explaining why measurability's scope is strictly broader than continuity's.

- If MC-2 recurs, re-anchor on the generating-set principle.
