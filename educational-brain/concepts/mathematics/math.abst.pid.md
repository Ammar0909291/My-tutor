## Learning Objective
Define a PRINCIPAL IDEAL DOMAIN (PID) as an integral domain where EVERY ideal is principal
(generated by one element), and PROVE every Euclidean Domain is a PID via the MINIMAL-NORM
argument, reusing `math.abst.euclidean-domain`'s own division-with-remainder property directly;
apply the PID-specific structural facts (every prime ideal is maximal; irreducibles equal
primes); and recognize the CONVERSE fails — not every PID is a Euclidean Domain.

## Core Understanding
EVERY EUCLIDEAN DOMAIN IS A PID — PROVEN, not merely asserted, via the MINIMAL-NORM-ELEMENT
argument: given any nonzero ideal $I$ in a Euclidean Domain $R$, take $d\in I$ with the SMALLEST
norm $N(d)$ among $I$'s nonzero elements (reusing `math.abst.euclidean-domain`'s own norm
function directly). For any $a\in I$, division gives $a=qd+r$ with $r=0$ or $N(r)<N(d)$; since
$I$ is an ideal, $r=a-qd\in I$ too — but $d$ was chosen MINIMAL, so $N(r)<N(d)$ is impossible
unless $r=0$. Hence every $a\in I$ is a multiple of $d$, so $I=(d)$ is PRINCIPAL. This holds for
every ideal, so $R$ is a PID — a DIRECT consequence of the already-mastered Euclidean property,
never an independently-verified new fact.

PID STRUCTURE IS GENUINELY PID-SPECIFIC, not automatic in every integral domain: in a PID, EVERY
nonzero prime ideal is automatically MAXIMAL, and every IRREDUCIBLE element is automatically
PRIME (and vice versa). A general integral domain can have irreducible elements that FAIL to be
prime — a genuinely weaker situation the PID guarantee specifically rules out.

THE CONVERSE FAILS — PID does NOT imply Euclidean Domain: the celebrated example
$\mathbb Z\left[\frac{1+\sqrt{-19}}2\right]$ IS a PID (every ideal genuinely principal) yet
admits NO possible Euclidean norm function whatsoever, confirming PID is a strictly BROADER class
of rings than Euclidean Domain, not merely a differently-named equivalent class.

## Mental Models
- **"PID status for a Euclidean Domain is a PROVEN consequence of the minimal-norm argument —
  never a fact requiring independent, separate verification."**
- **"PID is strictly BROADER than Euclidean Domain — every ED is a PID, but the reverse
  genuinely fails, with a historically significant separating example."**

## Why Students Fail

### MC-1: PID-STATUS-ASSUMED-TO-NEED-INDEPENDENT-VERIFICATION
- **Surface form**: believes PID status must be checked SEPARATELY for a Euclidean Domain,
  missing that it is a direct, provable consequence of the minimal-norm argument.
- **Birth type**: Type 1, overgeneralization (Blueprint's own declared Foundational severity —
  most new ring-theoretic properties DO require independent verification, so a learner
  over-applies that general pattern here, not recognizing this specific implication is already
  proven).
- **Repair**: re-walk the minimal-norm proof directly, re-anchoring on "PID status follows
  automatically, via minimal-norm elements, from the Euclidean property already mastered."

### MC-2: PID-STRUCTURE-ASSUMED-GENERAL-TO-ALL-DOMAINS
- **Surface form**: believes "every prime ideal is maximal" and "irreducibles equal primes" hold
  in ANY integral domain, missing that these are PID-SPECIFIC structural guarantees.
- **Birth type**: Type 1, overgeneralization (Blueprint's own declared Foundational severity —
  these facts are introduced alongside PID's own definition, so a learner can mistake
  PID-specific structure for a universal property of all integral domains).
- **Repair**: re-verify the maximality check concretely in a PID (e.g. $\mathbb Z$), re-anchoring
  on "this structure is PID-specific, not guaranteed in every domain."

### MC-3: PID-AND-ED-ASSUMED-EQUIVALENT
- **Surface form**: believes PID and Euclidean Domain are EQUIVALENT classes of rings, missing
  the genuine, historically significant separating counterexample.
- **Birth type**: Type 1, overgeneralization (Blueprint's own declared Moderate severity — since
  "every ED is a PID" is proven and every concrete example encountered so far happens to be both,
  the one-directional implication is mistaken for a two-directional equivalence).
- **Repair**: re-cite the specific separating example $\mathbb Z\left[\frac{1+\sqrt{-19}}2\right]$
  directly, re-anchoring on "PID is a strictly larger class than Euclidean Domain."

## Analogies
- **"The minimal-norm argument is like proving a shortest path exists by taking the shortest
  candidate and showing anything else reduces to it — the minimal element in $I$ generates
  everything else in $I$ by the same 'reduce to the minimum' logic as the Euclidean Algorithm."**
- **Anti-analogy**: PID does NOT mean "has a norm function" — a PID need not admit ANY Euclidean
  norm at all, as the $\mathbb Z\left[\frac{1+\sqrt{-19}}2\right]$ example proves.

## Demonstrations
- **Demonstration 1 (targets LO1/MC-1)**: in $\mathbb Z$ (norm $N(a)=|a|$, already mastered), let
  $I$ be a nonzero ideal with minimal element $d$; for any $a\in I$, division $a=qd+r$ with
  $r=a-qd\in I$ forces $r=0$ by $d$'s minimality — so $I=(d)$, confirming $\mathbb Z$ is a PID
  directly from its already-known Euclidean structure, with no separate check needed.
- **Demonstration 2 (targets LO2/MC-2)**: in $\mathbb Z$, is $(7)$ maximal? Every ideal of
  $\mathbb Z$ is $(n)$ for some $n$; $(7)\subseteq(n)$ exactly when $n\mid7$, giving only
  $n\in\{\pm1,\pm7\}$ — no ideal sits strictly between $(7)$ and $\mathbb Z$, confirming
  maximality, exactly matching the PID structure theorem's guarantee (which would NOT be
  automatic in an arbitrary integral domain).
- **Demonstration 3 (targets LO3/MC-3)**: $\mathbb Z\left[\frac{1+\sqrt{-19}}2\right]$ IS a PID
  (every ideal genuinely principal, an established deep algebraic-number-theory result) yet
  admits NO Euclidean norm whatsoever — confirming "every PID is a Euclidean Domain" is FALSE,
  even though "every Euclidean Domain is a PID" (Demonstration 1's direction) is proven.

## Discovery Questions
1. "Once you know $R$ is a Euclidean Domain, must PID status be checked as a SEPARATE fact, or
   does it follow automatically?"
2. "Does 'every prime ideal is maximal' hold in ANY integral domain, or only in a PID
   specifically?"
3. "If $R$ is a PID, must $R$ also be a Euclidean Domain?"

## Teaching Sequence
1. **Anchor**: connect to `math.abst.euclidean-domain`'s own norm function and division-with-
   remainder property, framing PID status as a direct consequence rather than a separate fact.
2. **Misconception gate**: Demonstration 1's minimal-norm proof in $\mathbb Z$, isolating MC-1 by
   showing PID status is DERIVED, not independently verified.
3. **Conflict evidence**: Demonstration 2's concrete maximality check in $\mathbb Z$, isolating
   MC-2 by confirming this structure is genuinely PID-specific.
4. **Contrast pair**: Demonstration 3's PID/ED separation, isolating MC-3 by citing the specific
   non-Euclidean PID example.
5. **Mastery gate**: require a correct minimal-norm proof sketch for a new Euclidean Domain, a
   correct maximality verification for a specific prime ideal, and a correct explanation of why
   the PID/ED implication is one-directional, at the Blueprint's own stated MAMR of 4/5
   (⌈0.75×5⌉).

## Tutor Actions
- Never accept a claim that PID status needs separate, independent verification for a Euclidean
  Domain — require the minimal-norm argument to be invoked directly.
- Never accept "PID equals Euclidean Domain" — require the one-directional implication and its
  separating counterexample to be stated explicitly.

## Voice Teaching Notes
- Say "is that PID status proven directly from the Euclidean property, or checked separately?"
  whenever a Euclidean Domain's PID status is discussed.
- When "PID" and "Euclidean Domain" are used interchangeably, ask "does that equivalence actually
  hold both directions?"
