## Learning Objective
Construct the PRODUCT $\sigma$-algebra $\mathcal F_1\otimes\mathcal F_2$ (generated by measurable
rectangles $A\times B$) and the PRODUCT MEASURE $\mu_1\otimes\mu_2(A\times B)=\mu_1(A)\mu_2(B)$ —
the exact "multiply the pieces" idea already used for ordinary area, generalized to abstract
measure spaces; state FUBINI'S THEOREM (absolute integrability $\iint|f|\,d(\mu_1\otimes\mu_2)
<\infty$ FORCES the iterated integrals to agree, in either order); and recognize TONELLI's
relaxation for non-negative $f$ (order always freely switchable), while for sign-changing $f$
without absolute integrability, order can genuinely CHANGE the answer.

## Core Understanding
THE PRODUCT MEASURE IS THE SAME "MULTIPLY THE PIECES" IDEA ALREADY USED FOR AREA, GENERALIZED TO
ANY TWO MEASURE SPACES: for $A=[0,2]$, $B=[0,3]$ with ordinary 1-dimensional Lebesgue measure,
$\mu_1\otimes\mu_2(A\times B)=\mu_1(A)\mu_2(B)=2\times3=6$ — EXACTLY the rectangle's area,
matching the familiar $dA=dx\,dy$ computation that double integrals rely on directly. The
abstract product-measure construction, applied to ordinary length on each factor, reproduces
exactly this familiar area result — never an unrelated new idea.

FUBINI'S ABSOLUTE-INTEGRABILITY HYPOTHESIS IS ESSENTIAL WORK, NEVER A FORMALITY TO SKIP: for
$f(x,y)=xye^{-(x^2+y^2)}$ on $[0,\infty)^2$: verifying $\iint|f|\,dA=\left(\int_0^\infty
xe^{-x^2}\,dx\right)\left(\int_0^\infty ye^{-y^2}\,dy\right)=\frac12\times\frac12=\frac14<\infty$
is a NECESSARY prior step BEFORE concluding the iterated integrals agree (both orders give
$\frac14$). Checking absolute integrability isn't a box ticked mechanically — it's the specific
hypothesis GUARANTEEING switching order is safe.

WITHOUT ABSOLUTE INTEGRABILITY, INTEGRATION ORDER CAN GENUINELY CHANGE THE ANSWER — NEVER
MERELY A THEORETICAL WARNING: the classic $f(x,y)=\frac{x^2-y^2}{(x^2+y^2)^2}$ on $[0,1]^2$ has
$\int_0^1\int_0^1f\,dy\,dx=\frac\pi4$ but $\int_0^1\int_0^1f\,dx\,dy=-\frac\pi4$ — GENUINELY
DIFFERENT, because $\iint|f|\,dA=\infty$ (absolute integrability FAILS). Skipping the
absolute-integrability check here produces a demonstrably WRONG, order-dependent answer. Tonelli
relaxes this ONLY for non-negative $f$: both orders always agree (possibly both $+\infty$), no
finiteness check needed, since there are no sign issues to create disagreement.

## Mental Models
- **"The product measure is width times height, generalized — the same multiplication idea now
  applied to any two measure spaces, not just ordinary lengths."**
- **"Checking absolute integrability before switching order is like checking a bridge's load
  rating before crossing it — skip it and the answer can genuinely collapse into something
  wrong."**

## Why Students Fail

### MC-1: PRODUCT-MEASURE-ASSUMED-UNRELATED-TO-AREA
- **Surface form**: believes the product measure construction is an unrelated new idea,
  disconnected from the familiar "area equals width times height" computation.
- **Birth type**: Type 1, overgeneralization (Blueprint's own declared Foundational severity — the
  abstract $\sigma$-algebra/measure notation obscures the concrete multiplication underneath).
- **Repair**: re-walk the direct rectangle-area match, re-anchoring on the same multiplication
  idea generalized.

### MC-2: ORDER-SWITCHING-ASSUMED-ALWAYS-SAFE
- **Surface form**: believes integration order can always be switched as long as both iterated
  integrals are individually computable.
- **Birth type**: Type 1, overgeneralization (Blueprint's own declared High severity — both orders
  being individually well-defined feels sufficient without checking they AGREE).
- **Repair**: re-walk the explicit absolute-integrability verification, re-anchoring on it as
  essential, not a formality.

### MC-3: FAILED-ABSOLUTE-INTEGRABILITY-ASSUMED-HARMLESS
- **Surface form**: believes switching order still typically gives the same answer even when
  absolute integrability fails.
- **Birth type**: Type 2, perceptual intuition (Blueprint's own declared Moderate severity —
  "smooth-looking" functions intuitively feel safe to reorder regardless of the formal check).
- **Repair**: re-walk the genuine order-dependence counterexample, re-anchoring on the two orders
  disagreeing.

## Analogies
- **"The product measure is a spreadsheet's row-total times column-total logic, generalized —
  multiply the two independent measures to get the combined cell's size."**
- **Anti-analogy**: passing Fubini's absolute-integrability check is NOT optional insurance — the
  classic counterexample shows skipping it can flip the sign of the answer entirely.

## Demonstrations
- **Demonstration 1 (targets MC-1)**: $\mu_1\otimes\mu_2([0,2]\times[0,3])=2\times3=6$, matching
  ordinary rectangle area exactly.
- **Demonstration 2 (targets MC-2)**: $f(x,y)=xye^{-(x^2+y^2)}$: $\iint|f|=\frac14<\infty$,
  Fubini guarantees both iteration orders give $\frac14$.
- **Demonstration 3 (targets MC-3)**: the classic $\frac{x^2-y^2}{(x^2+y^2)^2}$ counterexample:
  $+\pi/4$ one order, $-\pi/4$ the other, since $\iint|f|=\infty$.

## Discovery Questions
1. "Is the product measure construction an unrelated new idea, or does it match the familiar
   width-times-height area computation?"
2. "Can you always switch the order of integration, as long as both iterated integrals happen to
   be individually computable?"
3. "If a function fails the absolute-integrability check, does switching order still typically
   give the same answer anyway?"

## Teaching Sequence
1. **Representation shift**: state the product-measure construction directly, working
   Demonstration 1's rectangle-area match, isolating MC-1.
2. **Conflict evidence**: Demonstration 2's explicit absolute-integrability verification, isolating
   MC-2 by requiring the check performed BEFORE concluding order-independence.
3. **Contrast pair**: Demonstration 3's genuine order-dependence counterexample, isolating MC-3 by
   requiring the two orders' disagreement acknowledged.
4. **Mastery gate**: require a correct product-measure computation for a new rectangle, a correct
   absolute-integrability verification with the resulting order-independence guarantee stated, and
   a correct explanation of Tonelli's relaxed non-negativity hypothesis versus Fubini's, at the
   Blueprint's own KG-sourced MAMR of 4/5 (⌈0.8×5⌉).
