# Sets, Relations, and Functions — `cs.math.sets-relations-functions`

## Identity
- Prerequisite: `cs.math.discrete-mathematics`
- Unlocks: combinatorics and counting
- Difficulty / Bloom: developing / apply

## Learning objective
Perform set operations, classify basic relation properties, and determine whether mappings are functions and bijections.

## Core understanding
Sets are unordered collections of distinct elements. Relations are sets of ordered pairs and may associate an input with several outputs. A function assigns exactly one output to every input; distinct inputs may share an output. Injective, surjective, and bijective describe additional properties.

## Misconceptions
- **M1 — Every relation is a function.** Correction: a relation can give one input multiple outputs or omit a domain input.
- **M2 — A function is invalid if two inputs share an output.** Correction: many-to-one mappings are valid functions; each input still has exactly one output.

## Teaching and assessment notes
Use small mapping diagrams and require learners to check definitions before classifying a relation.
