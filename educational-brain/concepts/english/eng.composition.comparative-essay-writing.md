## Learning Objective
The learner will organize a comparative essay by POINT (each paragraph addressing one shared category of comparison across both items) rather than by BLOCK (fully describing one item, then the other), explicitly state the comparative relationship within each point, and select genuinely meaningful comparison points rather than trivial ones.

## Core Understanding
A comparative essay's defining organizational discipline is POINT structure, not BLOCK structure: each paragraph addresses one shared category (a theme, a technique, an effect) across BOTH texts, explicitly stating the similarity or difference — rather than fully describing Text A, then fully describing Text B, and leaving the actual comparing work implicit or absent. Block structure produces two separate essays stapled together with no comparison ever stated on the page. The second essential discipline is SELECTING comparison points with real analytical substance — a genuinely meaningful point reveals something about the works' themes, techniques, or effects (e.g., both texts explore isolation but frame it with opposite emotional valence), while a trivial point (both have chapters, one is longer) is technically true but analytically empty.

## Mental Models
- **Two-Separate-Restaurant-Reviews Anchor**: writing two completely separate restaurant reviews and expecting the reader to deduce which restaurant is better on any specific dimension by comparing the reviews themselves — the actual comparing work never happens on the page. A genuine comparative essay does that comparing work explicitly, point by point.
- **Movie-Runtime-Comparison Anchor**: a movie review spending a paragraph comparing two films' runtimes in minutes while never discussing what the films mean or how they achieve their effects — technically a true comparison, analytically empty. This is the retrievable test for trivial vs. substantive comparison points.

## Why Students Fail
Block structure feels natural because it mirrors how learners already know how to write about one text at a time — extending that habit to two texts sequentially requires no new organizational thinking, so the actual comparative work (explicitly stating relationships) gets skipped. Separately, trivial comparison points are the easiest to spot (both are true, observable facts), so learners reach for them first without evaluating analytical significance.

## Misconceptions
- **MC-A (Type 5, instruction-induced from single-text essay habits carried over)**: "A comparative essay means fully describing one item, then fully describing the other." Diagnostic: present a block-structured outline (three paragraphs on Text A, three on Text B, no comparison paragraph) alongside a point-structured outline (three shared-category paragraphs, each comparing both) and ask whether the block structure ever explicitly compares anything. Repair: two-restaurant-reviews anchor — reorganize by shared category, explicitly stating the comparison in each paragraph.
- **MC-B (Type 1, overgeneralization from "any true similarity/difference counts")**: "Any superficial similarity or difference is a meaningful point of comparison worth a paragraph." Diagnostic: present a trivial point ("both texts have chapters") against a substantive one ("both explore isolation but with opposite emotional valence") and ask whether the first reveals anything meaningful. Repair: movie-runtime anchor — before selecting a point, ask whether it reveals something about the works' themes, techniques, or effects.

## Analogies
- Two-separate-restaurant-reviews anchor (above) for point-vs-block structure.
- Movie-runtime-comparison anchor (above) for substantive-vs-trivial point selection.
- Anti-analogy: point structure does not mean avoiding all description of each text — description is necessary WITHIN each point paragraph to support the specific comparison; the flaw in block structure is that the comparison itself is never stated, not that description exists at all.

## Demonstrations
- Convert a block-structured outline for two short stories into a point-structured one, identifying shared categories.
- Sort five candidate comparison points for a text pair into trivial vs. substantive, explaining what (if anything) each reveals.
- Revise a paragraph that describes both texts on one point without ever stating the comparative relationship, adding an explicit "while/whereas" connection.

## Discovery Questions
- "Does this paragraph ever explicitly say how Text A and Text B compare on this point, or does it just describe them side by side?"
- "What does this comparison point actually reveal about what these texts are doing or mean?"
- "If I only read your point-based paragraphs, would I understand the comparison — or would I need to read both texts myself to figure it out?"

## Teaching Sequence
1. Diagnostic: rhetorical-analysis check (single-text synthesis, the prerequisite).
2. Anchor: two-restaurant-reviews and movie-runtime framing together.
3. TA-1: convert a block outline to a point outline (targets MC-A).
4. TA-2: revise a point-paragraph to explicitly state the comparative relationship.
5. TA-3: rank candidate comparison points by significance, discarding trivial ones (targets MC-B).
6. TA-4: full comparative essay outline — select substantive points, organize by point, draft one explicit-comparison paragraph.

## Tutor Actions
- SHOW: block vs. point outline pair; trivial vs. substantive comparison point pair.
- DO: learner reorganizes their own block-structured draft into point structure.
- TEST-THINKING: rank five candidate comparison points and justify the ranking.
- ORGANIZE: a point-based planning template (categories first, then draft) as scaffolding.

## Voice Teaching Notes
If a learner's comparison points are substantive but their prose still reads as two adjacent descriptions, prompt for an explicit "while/whereas/similarly" sentence structure connecting both texts within the same sentence — this is a common gap between correct point SELECTION and correct point EXECUTION.

## Assessment Signals
- Probe: "Convert this block outline into a point outline." Correct answer identifies shared categories present across both blocks; MC-A response merely relabels the block sections.
- Probe: given four candidate comparison points, "identify which are trivial and which are substantive." A learner who rates all four as equally valid signals MC-B.
- Confident-wrong signature: a technically accurate but analytically empty comparison point defended as "true, so it counts" — flag MC-B regardless of factual accuracy.

## Tutor Recovery Strategy
If a learner struggles to generate any candidate comparison points at all, provide a starter list of common comparison categories (theme, structure, tone, technique, effect on the reader) as a brainstorming aid before the significance-ranking step — the gap may be generative, not evaluative.

## Memory Hooks
"Two restaurant reviews that never compare" for point-vs-block; "runtime in minutes vs. what the film means" for trivial-vs-substantive.

## Transfer Connections

## Cross-Subject Connections
The point-vs-block distinction mirrors comparative analysis in any discipline — comparing two historical events, two scientific theories, or two experimental conditions by shared dimension rather than describing each fully in isolation is the same organizational discipline under a different subject.
