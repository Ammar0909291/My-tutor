# Question Formation — `eng.grammar.question-formation`

## Identity

- **Curriculum location**: English / grammar / "Question Formation" —

- **Unlocks** (from KG): none listed — this is a terminal node in the

## Learning Objective

The learner can:
1. Form yes/no questions from statements that already contain an
   auxiliary or "be" verb, by inverting that existing word with the
   subject.
2. Form yes/no questions from statements with no existing auxiliary, by
   inserting do/does/did and reverting the main verb to its base form.
3. Form wh-questions by placing the question word AND applying the
   correct inversion or do-insertion to the remainder of the sentence.
4. Distinguish subject-questions (where the wh-word itself is the
   subject, requiring no inversion) from object-questions (which do
   require inversion).
5. Apply correct question-formation rules across different tenses and
   modal-containing sentences, integrating all prior patterns.

## Core Understanding

Forming a question in English is not one universal move — it is a
BRANCHING decision with a single, checkable first step: does the
statement ALREADY contain an auxiliary verb (is, are, was, were, has,
have, can, will, etc.) or the verb "be"? If YES, simply INVERT that
existing word with the subject ("She is coming" → "Is she coming?"). If
NO, INSERT do/does/did and revert the main verb to its base form ("She
likes tea" → "Does she like tea?"). Critically, these two paths are
mutually exclusive — a sentence that already has an auxiliary NEVER
also needs do/does/did added on top ("Does she is coming?" is a genuine
double-auxiliary error). A second, equally load-bearing fact governs
wh-questions: placing the question word at the front is NOT sufficient
on its own — the same inversion-or-do-insertion rule from yes/no
questions must ALSO be applied to the rest of the sentence ("Where are
you going?" not "Where you are going?"). The one genuine exception is
when the wh-word itself IS the subject ("Who called you?") — here, no
inversion is needed at all, since there is no separate subject to swap
with an auxiliary.

## Mental Models

- **Beginner model — "add do/does/did to any statement to make it a
  question, and putting a question word at the front is enough"**: the
  arriving, pre-instructional model this concept exists to correct — a
  natural default because do/does/did IS the correct, reliable pattern
  for the large class of simple-tense statements without an existing
  auxiliary, and because the question word itself is such a clear,
  visible interrogative signal that it feels sufficient on its own.
- **Intermediate model — "I check for an existing auxiliary first: if
  present, I invert it; if absent, I insert do/does/did"**: installed by
  TA-1 and TA-2, using the Component 3 word-swap flip-cards anchor,
  resolving MC-JUST-ADD-DO-TO-ANY-STATEMENT. Upgrade trigger: correctly
  choosing inversion over do-insertion for a fresh sentence that already
  contains "is," "can," or "has," without defaulting to do/does/did.
- **Advanced model — "I apply the same invert-or-insert-do rule after a
  wh-question word, not just before it"**: installed by TA-3, resolving
  MC-WH-QUESTIONS-DONT-NEED-INVERSION by directly demonstrating that the
  question word alone leaves an incomplete, statement-ordered
  remainder.
- **Expert model — "I distinguish subject-questions (no inversion
  needed) from object-questions (inversion required), and I apply
  question-formation correctly across all tenses and modal-containing
  sentences"**: installed by TA-4 and TA-5, the concept's genuine
  mastery bar — handling the one true exception case and generalizing
  the full mechanism across the tense system already secured.
- **Do not upgrade early**: per the Blueprint's own Protocol Routing, for
  S9 learners whose L1 forms questions via a question particle or
  intonation alone, with no word-order change (many East Asian
  languages), or uses a different inversion convention, expect this
  concept's core mechanism (subject-auxiliary inversion, do-support) to
  be a genuinely novel, challenging structural feature with no direct
  parallel in many world languages — requiring substantial, dedicated
  practice, not assumed intuitive transfer.

## Why Students Fail

Two independent failure mechanisms operate here. The add-do-to-any-
statement failure exists because do/does/did genuinely IS the correct
mechanism for the large, common class of simple-tense statements
without an existing auxiliary — over-applying it universally is a
reasonable extension of real, frequently-correct evidence, with nothing
marking the exception (sentences already containing an auxiliary) until
a learner is directly shown that "Does she is coming?" produces a
genuine double-auxiliary error. The wh-questions-dont-need-inversion
failure exists because the question word itself is such a visually
salient, unmistakable interrogative marker that it reasonably FEELS
sufficient on its own — nothing marks the additional inversion
requirement until a learner directly compares "Where you are going?"
against the correct "Where are you going?" and is asked whether the
part after the question word still needs the same restructuring used in
yes/no questions.

## Misconceptions

The existing Blueprint (`docs/curriculum/blueprints/
eng.grammar.question-formation.md`, Component 1) documents both
misconceptions this concept produces, with full trigger/probe/bridge/
replacement/discrimination content — reused by reference below, with
birth-type classification added
(`../../misconceptions/01-birth-taxonomy.md`).

**MC-JUST-ADD-DO-TO-ANY-STATEMENT (Blueprint Component 1) — Type 1,
overgeneralization**
- *Why (birth-type addition)*: exact Type 1 signature — do/does/did
  genuinely IS the correct rule for a large, frequently-encountered
  class of statements, so extending it universally is a reasonable
  generalization from real, mostly-correct partial evidence; the
  misconception survives because the do/does/did pattern is highly
  reliable and easy to apply mechanically, delaying the moment an
  already-auxiliary-containing sentence directly contradicts it.
- *Full trigger/probe/bridge/replacement/discrimination content*: see
  Blueprint Component 1, verbatim — not restated here.
- *Characteristic phrase (addition)*: a learner who, when meeting a
  fresh statement already containing "is," "can," or "has,"
  spontaneously inverts that existing word rather than reaching for
  "does" first is showing the auxiliary-check-first discipline has been
  genuinely internalized.

**MC-WH-QUESTIONS-DONT-NEED-INVERSION (Blueprint Component 1) — Type 1,
overgeneralization**
- *Why (birth-type addition)*: exact Type 1 signature — the question
  word itself is such a visually salient, unmistakable interrogative
  marker that treating it as sufficient on its own is a reasonable
  generalization until directly shown that the remainder of the
  sentence still requires the same restructuring used in yes/no
  questions.
- *Full trigger/probe/bridge/replacement/discrimination content*: see
  Blueprint Component 1, verbatim — not restated here.
- *Characteristic phrase (addition)*: a learner who, when forming a
  fresh wh-question, spontaneously applies the inversion or do-
  insertion rule to the remainder of the sentence AFTER placing the
  question word, without being told, is showing the same-mechanism
  insight has generalized beyond the specific TA-3 practice items.

## Analogies

- **Best analogy — the word-swap flip cards itself is the analogy, not
  a supplement to it** (Blueprint Component 3): physically swapping
  existing card positions ("is" and "She") when an auxiliary is present,
  versus inserting a brand-new "does" card and modifying the verb card
  when none is present, directly embodies the two-path decision as a
  concrete, physically distinguishable action rather than an abstract
  rule to memorize. Breaking point: the flip-cards anchor demonstrates
  the base invert-vs-insert-do decision well but doesn't on its own
  address the wh-question-still-needs-inversion insight (TA-3) or the
  subject-question exception (TA-4), which need their own separate,
  dedicated demonstrations.
- **Alternative — a toll booth with two lanes**: one lane (invert) is
  for cars (sentences) that already have an EZ-Pass tag (an existing
  auxiliary) — they just get waved through in a different position; the
  other lane (insert-do) is for cars without a tag — they must stop and
  pick one up (add do/does/did) before proceeding. Breaking point:
  useful for the two-mutually-exclusive-paths insight, but doesn't
  address the wh-question extension or the subject-question exception,
  which the flip-cards anchor's own TA-3/TA-4 practice handles directly.
- **ANTI-ANALOGY — do NOT teach do/does/did insertion as "the" question
  rule with inversion as a special case**: this framing risks
  reinforcing MC-JUST-ADD-DO-TO-ANY-STATEMENT by implying do-support is
  the default and inversion is the exception; both paths are equally
  primary, equally common, mutually exclusive strategies selected by a
  single, symmetric first-step check (does an auxiliary already exist?)
  — neither is more "basic" than the other.

## Demonstrations

- **Physical/visual (the word-swap flip cards)**: the Blueprint's
  Component 3 anchor — canonical, referenced not restated.
- **Home/no-equipment**: any statement the learner can make about
  themselves or someone else supplies real TA-1/TA-2 material for both
  question-formation paths; any genuine curiosity the learner has about
  a person, place, or reason supplies real TA-3 wh-question material.
- **Interactive/learner-activity**: TA-4's subject-vs-object-question
  discrimination task (deciding whether inversion is needed based on
  whether the wh-word replaces the subject or the object) is inherently
  hands-on judgment practice, not mere recognition of a stated fact.
- **Teacher-demo (the already-there test)**: the tutor models the
  Blueprint's own conflict-evidence demonstration — asking whether "is"
  is already present in "She is coming," and whether a SECOND helping
  verb ("does") needs to be added on top, making the auxiliary-check-
  first discipline directly audible and testable.
- **Prediction to elicit FIRST, every time**: before confirming a
  question-formation attempt (TA-1 through TA-5), ask the learner to
  state their own attempt before the tutor confirms — Universal
  Principle 3.

## Discovery Questions

**A brief, argued discovery step suits both misconceptions.** The
auxiliary-check-first discipline and the wh-question-still-needs-
inversion insight are both genuine, directly testable phenomena well-
suited to guided discovery: **need** (the learner, having secured
TA-1's inversion practice, is asked to turn "She likes tea" into a
question using inversion alone, discovering there's no auxiliary to
invert, which motivates the do-insertion alternative); **playground/
invention** (TA-1's inversion practice and TA-2's do-insertion practice
build initial confidence with both paths independently before their
contrast is named); **collision** (the Blueprint's own "Does she is
coming?" probe breaks the add-do-to-everything assumption; the "Where
you are going?" probe breaks the wh-questions-dont-need-inversion
assumption); **formalization** (MP-5's own-words statement of both the
auxiliary-check-first rule and the wh-question-same-mechanism insight);
**compression** (TA-5's fluent question-formation across different
tenses and modal-containing sentences, applying the rule directly
without each instance separately re-derived). The specific terms
"subject-auxiliary inversion," "do-support," and "wh-question" are
convention-bound grammatical terminology best introduced by direct
instruction once the learner has already felt the underlying
distinctions through the flip-cards anchor and TA-1–3.

## Teaching Sequence

TA-1 (yes/no questions with existing auxiliaries, inversion) is placed
first as the concept's most mechanically direct entry point, per the
Blueprint's own flip-cards anchor — establishing the inversion path
before any complication is introduced. TA-2 (yes/no questions requiring
do/does/did) follows immediately, directly targeting
MC-JUST-ADD-DO-TO-ANY-STATEMENT through explicit contrast with TA-1 —
per the Blueprint's own session architecture, this conflict-evidence
probe is placed right after TA-2, once the learner has secure practice
with both paths to contrast. TA-3 (wh-questions with inversion) extends
the now-secure base mechanism to the wh-question structure, directly
targeting MC-WH-QUESTIONS-DONT-NEED-INVERSION. TA-4 (wh-questions
asking about the subject, no inversion needed) introduces the one
genuine exception case, addressing a SECOND, independent dimension
(subject-vs-object question type, not the invert-vs-insert-do
decision) once the base wh-question mechanism is secure. TA-5 (forming
questions in different tenses) is placed last as the concept's
integration capstone, generalizing the full mechanism across the tense
and modal system the learner already secured. This entry does not
restate the Blueprint's own turn-by-turn session script (Component 7)
— see Blueprint References below.

## Voice Teaching Notes

- **What to listen for**: whether the learner spontaneously checks for
  an existing auxiliary before defaulting to do/does/did on a fresh
  statement, and whether the learner spontaneously applies inversion or
  do-insertion to the remainder of a fresh wh-question sentence (rather
  than stopping at the question word) — these are the primary
  diagnostic signals for whether TA-2 and TA-3's disciplines have
  genuinely generalized beyond the specific practice items.
- **Characteristic hesitations**: a brief pause before choosing between
  inversion and do-insertion for a fresh statement, followed by a
  correct, auxiliary-presence-consistent choice, suggests the learner
  is consciously checking rather than defaulting to one strategy — a
  good sign. Instant, confident insertion of "does" onto a sentence that
  already has "is" or "can" (without self-correction) is the concerning
  pattern for MC-JUST-ADD-DO-TO-ANY-STATEMENT.
- **Native-intuition-gap stakes**: real and specifically named in the
  Blueprint's own Protocol Routing — for S9 learners whose L1 forms
  questions via a particle or intonation alone, reassure that subject-
  auxiliary inversion and do-support are genuinely novel structural
  features with no direct parallel in many world languages, requiring
  substantial, dedicated, structured practice, not assumed intuitive
  transfer.
- **The load-bearing sentence**: "does the sentence already have a
  helping verb, or do we need to add one?" is this concept's load-
  bearing sentence for MC-JUST-ADD-DO-TO-ANY-STATEMENT, per
  `../../foundations/03-voice-first-learning-model.md §3` — asked
  whenever a fresh statement is about to be turned into a question,
  making the auxiliary check a routinely-invited response rather than
  an afterthought.

## Tutor Recovery Strategy

Concept-specific application of `../../foundations/01-recovery-engine.md`:
- **"I don't know"** on a question-formation task shrinks to the
  Component 3 flip-cards anchor using the simplest, most familiar
  existing-auxiliary example available, with the tutor modeling the
  inversion before the learner attempts a fresh do-insertion or
  wh-question sentence independently.
- **Likeliest utterance/behavior at this node**: for
  MC-JUST-ADD-DO-TO-ANY-STATEMENT, producing a double-auxiliary error

  MC-WH-QUESTIONS-DONT-NEED-INVERSION, leaving the sentence in statement

  spontaneously self-corrects from a double-auxiliary attempt to the
  correct inverted form ("Does she is — wait, is she coming?") before
  being told is showing the auxiliary-check-first discipline has
  generalized — this should be named and praised explicitly, per the
  Blueprint's own regulation-tail guidance (praising checking for
  existing auxiliaries before applying do/does/did).

## Memory Hooks

**Concept type**: procedural/framework — a branching, two-path
production system (invert existing auxiliary vs. insert do/does/did)
extended to wh-questions with one genuine exception (subject-
questions), applied to genuinely novel statements across all tenses;
mastery is demonstrated by correctly forming fresh questions across all
paths (MP-1 through MP-4) rather than by recognizing a fixed,
previously-taught example list. Interleaving partners: mix inversion
items (testing TA-1) with do-insertion items (testing TA-2) and
wh-question items including both the base case and the subject-
question exception (testing TA-3/TA-4) in ongoing review, so the
learner continues exercising the active auxiliary-presence-check
judgment rather than defaulting to whichever path was most recently
practiced.
