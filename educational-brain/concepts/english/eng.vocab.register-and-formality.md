# Register and Formality — `eng.vocab.register-and-formality`

## Identity

- **Concept ID**: `eng.vocab.register-and-formality` (canonical
  English KG)
- **Curriculum location**: English / vocab / "Register and Formality"
  — choosing vocabulary appropriate to a communicative context, ranging
  from informal/colloquial to formal/academic register, taught as a
  context-fit scale rather than a correctness scale, with explicit
  attention to mismatch in BOTH directions.
- **Prerequisites**: `eng.vocab.connotation-denotation` — load-bearing
  because register is largely built from connotation-consistent
  patterns of word choice; a learner who cannot reliably detect a
  word's formality/connotation shading (frugal vs. cheap, casual vs.
  clinical) has no reliable basis for judging which register a broader
  set of word choices collectively signals.
- **Unlocks** (from KG): `eng.vocab.academic-vocabulary`,
  `eng.communication.digital-communication`. Academic vocabulary
  presupposes the learner already accepts formal register as
  situationally appropriate, not "try-hard" or pretentious; real-time,
  cross-platform register judgment (text vs. email vs. formal document)
  is this concept's own core skill applied across communication
  channels rather than only written genres.
- **Difficulty**: advanced · **Bloom**: analyze · **Mastery threshold**:
  0.75 · **Est. hours**: 2

## Learning Objective

The learner can:
1. Sort language samples by register (very informal / neutral / very
   formal) and name the likely audience and purpose for each,
   reasoning from audience+purpose rather than from any inherent word
   quality.
2. Identify concrete linguistic markers of register — contractions vs.
   full forms, personal vs. impersonal constructions, slang vs.
   technical vocabulary, fragments vs. complete sentences, direct
   address vs. formal titles.
3. Detect register mismatch in BOTH directions — an overly formal
   message in a casual context, and an overly casual message in a
   formal context — recognizing both as genuine errors of equal
   standing.
4. Convert a message from one register into other target registers
   while preserving its core content/request.
5. Independently choose and justify an appropriate register for a
   novel, unscripted real-world scenario, naming the audience/
   relationship/purpose factors driving the choice.

## Core Understanding

Register is a matter of CONTEXT FIT, not a single correctness scale
where more formal always scores higher — formal English is not
"better" English, it is a different tool for a different job, the same
way a tuxedo is not "more correct" clothing than swim trunks, only
correct for a different occasion. Using a hyper-formal register with a
close friend does not sound more proper, it sounds strange or even
sarcastic; the "best" register in any situation is whichever one fits
the audience, purpose, and relationship, and neither casual nor formal
register is inherently superior English. A second, equally load-bearing
fact — the mirror image of the first — is that informal register is not
"bad grammar" or sloppy writing to be corrected: contractions, sentence
fragments used for effect, colloquial vocabulary, and casual sentence-
starting conventions are deliberate, legitimate, rule-governed choices
suited to speed, closeness, and everyday contexts, following their own
real conventions rather than being deviations from formal rules. A
text message that reads like a legal letter has failed at its
communicative job just as thoroughly as a job application that reads
like a text message — mismatched register in EITHER direction is the
actual error, never informality or formality by itself.

## Mental Models

- **Beginner model — "the more formal my writing/speech is, the more
  correct and impressive it is, in any context"**: the arriving,
  pre-instructional model this concept exists to correct — a natural
  extension of formal-writing instruction dominating much of a
  learner's prior schooling, which reasonably creates the impression
  that "proper English" scales linearly with formality, with nothing in
  that instruction marking that formality can be just as wrong as
  informality when it doesn't fit the actual context.
- **Intermediate model — "I can sort language samples by register and
  identify the concrete linguistic markers that signal formality
  level"**: installed by TA-1's audience/purpose sorting and TA-2's
  register-marker instruction, using the Component 3 Outfit Closet
  anchor to make the context-fit principle concrete. Upgrade trigger:
  correctly sorting a genuinely mixed, unlabeled set of samples by
  register while citing specific linguistic markers (not just
  intuition) as evidence.
- **Advanced model — "mismatched register is the real error, in EITHER
  direction — over-formal for a casual context is just as wrong as
  under-formal for a formal one"**: installed by TA-3's both-directions
  mismatch-detection task, resolving both MC-FORMAL-ALWAYS-MEANS-
  BETTER-OR-MORE-CORRECT and MC-INFORMAL-REGISTER-MEANS-BAD-GRAMMAR-OR-
  SLOPPY-WRITING as mirror-image failures of one underlying
  misconception (formality-as-a-correctness-scale). Upgrade trigger:
  spontaneously identifying an over-formal mismatch as an error with
  the same seriousness as an under-formal one, without needing the
  symmetry pointed out.
- **Expert model — "I can convert a message across registers while
  preserving its content, and independently choose an appropriate
  register for a genuinely novel situation"**: installed by TA-4's
  register-conversion practice and TA-5's novel-situation capstone. Per
  the Blueprint's own explicit mastery gate, certification requires
  BOTH MP-1 (over-formal mismatch) and MP-2 (informal-is-not-an-error)
  to pass — a learner who passes only one of the two paired
  misconception probes has learned only half of this concept's
  symmetric lesson.
- **Do not upgrade early**: per the Blueprint's own explicit mastery-
  gate rule (Component 7's S9 protocol) and Adaptive Flags, watch
  closely for a ONE-DIRECTIONAL bias — a learner who only over-corrects
  toward formality (never recognizing over-formal mismatch as an error)
  or only over-corrects toward informality (never recognizing informal
  as legitimate) has an asymmetric, incomplete grasp of the concept
  requiring targeted remediation toward the specific direction they're
  missing, not a generic re-teach of the whole concept.

## Why Students Fail

Two independent failure mechanisms operate here, both mirror-image
consequences of the same underlying formality-as-correctness-scale
assumption. The over-formal-is-better failure exists because much of a
learner's prior explicit writing instruction (academic essays, formal
letters, school writing generally) genuinely does reward formal
register, and correcting toward greater formality genuinely IS the
right move in those specific contexts — so the learner reasonably
extends "more formal is better" as a general principle, with nothing in
that instruction marking the many everyday contexts where formal
register would actually be inappropriate. The informal-is-sloppy
failure exists for the identical reason from the opposite direction —
having internalized formal writing conventions as "correct English,"
the learner reasonably treats any deviation from those conventions
(contractions, fragments, casual vocabulary) as an ERROR relative to
that standard, with nothing marking that informal register follows its
own distinct, equally legitimate and rule-governed conventions rather
than being a degraded version of formal register.

## Misconceptions

The existing Blueprint (`docs/curriculum/blueprints/
eng.vocab.register-and-formality.md`, Component 1) documents both
misconceptions this concept produces, with full trigger/probe/bridge/
replacement/discrimination content — reused by reference below, with
birth-type classification added
(`../../misconceptions/01-birth-taxonomy.md`).

**MC-FORMAL-ALWAYS-MEANS-BETTER-OR-MORE-CORRECT (Blueprint Component
1) — Type 5, instruction-induced**
- *Why (birth-type addition)*: substantially reinforced by external
  instructional emphasis — formal writing instruction genuinely
  dominates much of a learner's explicit schooling (academic essays,
  formal letters), and correcting toward formality genuinely is the
  right move in those specific taught contexts, so the learner
  reasonably absorbs "more formal = more correct" as a general lesson
  from that instruction, rather than independently inventing the
  belief.
- *Full trigger/probe/bridge/replacement/discrimination content*: see
  Blueprint Component 1, verbatim — not restated here.
- *Characteristic phrase (addition)*: a learner who, when shown a
  maximally formal text message to a close friend, spontaneously says
  something like "that would sound really weird, like they're being
  sarcastic" before being told is showing the context-fit model has
  been genuinely internalized, rather than merely accepted after
  correction.

**MC-INFORMAL-REGISTER-MEANS-BAD-GRAMMAR-OR-SLOPPY-WRITING (Blueprint
Component 1) — Type 5, instruction-induced**
- *Why (birth-type addition)*: the identical instruction-induced
  mechanism as the first misconception, viewed from the opposite
  direction — formal-register conventions, having been explicitly
  taught as "correct English," naturally become the implicit reference
  standard against which any deviation (contractions, fragments,
  casual vocabulary) gets judged as an error, since the learner's most
  explicit language instruction rarely presents informal register's own
  conventions as an equally legitimate, separately rule-governed system.
- *Full trigger/probe/bridge/replacement/discrimination content*: see
  Blueprint Component 1, verbatim — not restated here.
- *Characteristic phrase (addition)*: a learner who, when asked to "fix"
  a well-written informal text message, responds with something like
  "actually, I don't think this needs fixing — it works fine for a
  quick text to a friend" is showing the register-is-not-a-correctness-
  scale model has been genuinely internalized.

## Analogies

- **Best analogy — the Outfit Closet itself is the analogy, not a
  supplement to it** (Blueprint Component 3): matching outfit cards
  (pajamas, gym clothes, business-casual, tuxedo) to event cards
  (sleeping, a run, a job interview, a wedding), with two explicit
  failure cases (a tuxedo to hang out with friends; pajamas to a job
  interview) shown as equally real errors in opposite directions,
  directly embodies register as context-fit rather than a single
  correctness scale. Breaking point: an outfit closet's five discrete
  outfit categories can imply register itself has exactly five clean
  levels, when real register exists on more of a continuous spectrum
  with considerable contextual nuance — this entry treats the closet
  framing as the introductory frame for the symmetric-mismatch
  principle specifically, not a claim that register reduces to five
  fixed categories.
- **Alternative — a toolbox with different tools for different jobs,
  not a single "best" tool**: a hammer isn't a "better" tool than a
  screwdriver in some absolute sense — each is the right tool for a
  specific job, and using a hammer where a screwdriver is needed (or
  vice versa) is the actual error. Breaking point: useful for
  reinforcing the no-single-best-register principle, but the outfit
  metaphor more directly captures the SOCIAL, relationship-and-audience-
  driven nature of register choice, which a toolbox's purely mechanical
  fit-to-task framing doesn't emphasize as strongly.
- **ANTI-ANALOGY — do NOT describe informal register as "relaxed
  rules" or "rules you can break"**: framing informal register as
  formal register with some rules loosened or ignored directly
  reinforces MC-INFORMAL-REGISTER-MEANS-BAD-GRAMMAR-OR-SLOPPY-WRITING by
  implying informal register is fundamentally a degraded or incomplete
  version of formal register; informal register should always be
  framed as its own distinct, equally legitimate, equally rule-governed
  system, not formal register with the rules relaxed.

## Demonstrations

- **Physical/visual (the Outfit Closet)**: the Blueprint's Component 3
  anchor — canonical, referenced not restated.
- **Home/no-equipment**: the outfit-matching activity can be described
  verbally or drawn on paper; the learner's own recent texts, emails,
  and school writing supply real TA-1/TA-4-style register-sorting and
  conversion practice.
- **Interactive/learner-activity**: TA-4's register-conversion task and
  TA-5's novel-situation capstone are both hands-on, requiring the
  learner to actively produce register-appropriate text, not merely
  recognize a stated fact.
- **Teacher-demo (both-direction mismatch contrast)**: the tutor models
  the Blueprint's own conflict-evidence demonstrations — an overly
  formal text to a sibling and an overly casual email to a school
  principal — making both directions of mismatch directly and
  memorably visible in a single session.
- **Prediction to elicit FIRST, every time**: before confirming a
  register sort (TA-1) or a mismatch judgment (TA-3), ask the learner to
  state their own judgment before the tutor confirms — Universal
  Principle 3.

## Discovery Questions

**A brief, argued discovery step suits both misconceptions, given their
mirror-image structure.** Context-fit and the both-directions mismatch
principle are both genuine, directly felt phenomena well-suited to
guided discovery: **need** (the learner, having secured connotation
sensitivity, is asked which of two versions of the same message to a
friend — casual or maximally formal — the friend would find normal);
**playground/invention** (TA-1's audience/purpose sorting across six
samples lets the learner notice the pattern applies broadly);
**collision** (the Blueprint's own casual-vs-hyperformal-to-a-friend
probe breaks the formal-is-better assumption; the well-written informal
text-message "fix" probe breaks the informal-is-sloppy assumption);
**formalization** (MP-5's novel-situation justification task, requiring
explicit naming of audience/relationship/purpose factors);
**compression** (TA-4's fluent register conversion without each marker
separately re-derived). The specific term "register" and the named
linguistic markers (contractions, passive/impersonal constructions,
etc.) are convention-bound terminology best introduced by direct
instruction once the learner has already felt the underlying context-
fit distinction through the anchor and TA-1.

## Teaching Sequence

TA-1 (audience and purpose sorting) is placed first as the concept's
foundational orienting task, establishing that register is read off
audience+purpose rather than off some inherent word quality, before any
specific linguistic markers are named. TA-2 (register markers) follows,
naming the concrete linguistic signals (contractions, passive
constructions, sentence fragments, etc.) the learner has just
implicitly used to sort TA-1's samples — placed after TA-1 specifically
so the markers are grounded in already-felt sorting judgments rather
than introduced as an abstract list to memorize first. TA-3 (register
mismatch detection, both directions) is placed next, directly targeting
both misconceptions simultaneously through paired, mirror-image
examples — per the Blueprint's own explicit design, this is deliberately
NOT split into two separate TAs addressing each misconception in
isolation, since the whole point is that both directions are the same
underlying error, best taught together. TA-4 (register conversion
practice) extends the now-secure recognition skill (TA-1–3) into
productive conversion, requiring the learner to actively generate
register-appropriate rewrites rather than only classify given samples.
TA-5 (choosing register for a novel situation) is placed last as the
concept's fully independent, generative capstone, requiring the learner
to make and justify a register choice from scratch with no register
specified in advance. This entry does not restate the Blueprint's own
turn-by-turn session script (Component 7) — see Blueprint References
below.

**What does NOT fit, and why**: Role-Play (`06-social-family.md`) in
its performative sense is deliberately excluded — while register choice
IS deeply social, the concept's practical skill is best built through
direct written-sample analysis and conversion (sorting, marker
identification, rewriting) rather than live performative role-play,
which would add complexity without sharpening the concept's core
context-fit and marker-recognition disciplines.

## Voice Teaching Notes

- **What to listen for**: whether the learner spontaneously identifies
  BOTH directions of mismatch when evaluating register-sensitive
  scenarios (rather than only ever flagging over-casual or only ever
  flagging over-formal) — this is the primary diagnostic signal for
  whether TA-3's symmetric, both-directions lesson has been genuinely,
  fully internalized rather than only half-learned.
- **Characteristic hesitations**: a brief pause before judging an
  informal-register sample as "correct" (rather than "sloppy"),
  followed by an explicit statement that it fits its context, suggests
  the learner is consciously overriding an internalized formal-as-
  correct default — a good sign, distinct from immediate, confident
  praise of an over-formal sample with no consideration of context fit.
- **Directional-bias stakes**: real and specifically named in the
  Blueprint's own Adaptive Flags — a learner showing only ONE direction
  of the symmetric lesson (always over-correcting toward formality, OR
  always treating formal writing as stuffy/wrong) needs remediation
  targeted at the SPECIFIC missing direction, not a generic re-teach of
  the whole concept.
- **The load-bearing sentence**: "who is this for, and what's the
  relationship?" is this concept's load-bearing sentence for both
  misconceptions, per
  `../../foundations/03-voice-first-learning-model.md §3` — asked
  whenever a fresh register-sensitive scenario is introduced, making
  audience/relationship analysis a routinely-invited first response
  rather than jumping straight to a formality judgment.

## Tutor Recovery Strategy

Concept-specific application of `../../foundations/01-recovery-engine.md`:
- **"I don't know"** on a register-sorting task shrinks to the
  Component 3 Outfit Closet anchor using the most clear-cut, extreme
  pair available (pajamas to a job interview vs. a tuxedo to hang out
  with friends), with the tutor modeling the outfit-to-event matching
  before the learner attempts a fresh language sample independently.
- **Likeliest utterance/behavior at this node**: a one-directional bias
  (confidently over-correcting toward formality, or confidently
  dismissing all formal writing as stuffy) is more likely than "I don't
  know" — per the Blueprint's own protocol routing, weight remediation
  toward the SPECIFIC missing direction (TA-3's informal-is-legitimate
  examples for an over-formality bias; TA-3's over-casual-to-authority
  examples for an anti-formality bias) rather than a generic re-teach.
- **Non-verbal signal specific to this node**: a learner who
  spontaneously asks "who is this actually for?" before judging a
  register-sensitive scenario, without being prompted, is showing the
  audience-first discipline has generalized — this should be named and
  praised explicitly.

## Memory Hooks

**Concept type**: procedure — an audience-and-purpose analysis routine
(identify audience/relationship/purpose, judge register fit rather than
formality level alone, detect mismatch in either direction) applied to
genuinely novel communicative scenarios, combined with a productive
register-conversion and independent-choice skill (TA-4/TA-5); mastery is
demonstrated by correctly identifying BOTH directions of mismatch
(MP-1/MP-2) and by independently choosing and justifying register for
novel scenarios (MP-5), not by recognizing a fixed, previously-taught
example list. Interleaving partners: mix over-formal-mismatch items
with under-formal/informal-legitimacy items in EVERY review session
(never testing only one direction), so the learner's grasp of the
symmetric lesson is continuously verified as complete rather than
one-sided.
