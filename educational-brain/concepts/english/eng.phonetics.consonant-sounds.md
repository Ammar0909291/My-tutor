# Consonant Phoneme Classification — `eng.phonetics.consonant-sounds`

## Identity

- **Concept ID**: `eng.phonetics.consonant-sounds` (canonical English
  KG)
- **Curriculum location**: English / phonetics / "Consonant Phoneme
  Classification" — the systematic full-inventory extension of the
  prerequisite concept's introductory place/manner/voicing vocabulary,
  applied to the entire English consonant system.
- **Prerequisites**: `eng.phonetics.articulation-organs` — specifically
  the physical articulator vocabulary, the buzz-test voicing procedure,
  and the introductory place/manner categories; load-bearing because
  this concept does not introduce new TESTS, only extends their
  systematic application from a handful of illustrative sounds to the
  complete English consonant inventory.
- **Unlocks** (from KG): `eng.phonetics.ipa-basics`. The formal IPA
  symbol system is organized by exactly the place/manner/voicing
  dimensions this concept systematizes — a learner cannot map IPA
  symbols meaningfully onto sounds without already possessing a
  reliable, tested classification for each one.
- **Difficulty**: developing · **Bloom**: understand · **Mastery
  threshold**: 0.75 · **Est. hours**: 3

## Learning Objective

The learner can:
1. Classify any English consonant by place of articulation across the
   full inventory (bilabial through glottal).
2. Classify any English consonant by manner of articulation across the
   full inventory (stop, fricative, affricate, nasal, liquid, glide).
3. Determine voicing for any consonant using the buzz test, organizing
   voiced/voiceless cognate pairs that share place and manner.
4. Produce a complete three-dimension classification (place + manner +
   voicing) for a given sound without scaffolding.
5. Apply the three-test classification procedure live to a genuinely
   novel or unfamiliar sound, rather than relying on memorized labels.

## Core Understanding

The place/manner/voicing framework introduced at a small scale in the
prerequisite concept is not a list of facts about specific sounds — it
is a general, repeatable DIAGNOSTIC METHOD that applies to any
consonant, including ones the learner has never explicitly classified
before. This is the single most consequential fact this concept must
install, because the alternative — treating classification as a fixed
table of memorized labels — fails precisely where the method matters
most: on unfamiliar sounds, including sounds from a learner's own first
language that the English-only inventory never covers. A second,
equally load-bearing fact is that the three dimensions are not
independently sufficient — no single dimension, and not even two of the
three, uniquely identifies a consonant (voiceless + bilabial alone is
still ambiguous; only voiceless + bilabial + stop pins down /p/
specifically) — a complete description always requires all three
dimensions stated together.

## Mental Models

- **Beginner model — "I can apply the place, manner, and voicing tests
  to systematically work through a large set of consonants"**: installed
  by TA-1 through TA-3, which extend the prerequisite concept's small
  illustrative set to the FULL English consonant inventory,
  systematically, one dimension at a time. This is scale-up of an
  already-secure skill, not new conceptual content.
- **Intermediate model — "a complete classification requires all three
  dimensions stated together, never fewer"**: installed by TA-4,
  resolving MC-PLACE-MANNER-VOICING-ARE-INDEPENDENT directly through
  the conflict-evidence demonstration that partial descriptions remain
  genuinely ambiguous. Upgrade trigger: spontaneously stating all three
  dimensions together without being separately prompted for each one.
- **Advanced model — "cognate pairs (sharing place and manner, differing
  only in voicing) organize the whole system into manageable chunks"**:
  an organizing strategy this entry treats as load-bearing content in
  its own right, per the Blueprint's own explicit Adaptive Flag naming
  cognate-pair chunking as "substantially reducing cognitive load" for
  what would otherwise be an undifferentiated list of roughly 24
  consonants.
- **Expert model — "the three-test method is a general tool I can apply
  to a sound I have never classified before, including a non-English
  sound"**: installed by TA-5, resolving MC-CLASSIFICATION-IS-JUST-
  LABELING — the genuine mastery bar for this concept, per the
  Blueprint's own explicit statement, is demonstrated method application
  on novel material, not recall of previously-drilled labels.
- **Do not upgrade early**: a learner not yet secure applying the three
  tests reliably to the FAMILIAR sounds from the prerequisite concept
  (TA-1/TA-2) should not be given TA-5's novel-sound challenge — the
  novel-sound test is only diagnostic of genuine method-possession
  (versus memorization) if the underlying tests themselves are already
  reliable when applied to anything.

## Why Students Fail

Two independent failure mechanisms operate here. The labeling-not-
method failure exists because memorizing a small set of pre-classified
sounds (a handful of illustrative examples from the prerequisite
concept) is genuinely faster and lower-effort than internalizing and
re-applying a three-step diagnostic procedure each time — a learner
under normal study-effort incentives will reasonably gravitate toward
the memorization shortcut unless the assessment explicitly and
repeatedly requires live application to material the shortcut cannot
cover. The dimension-independence failure exists because each of the
three tests (touch for place, airflow-shape for manner, buzz for
voicing) is taught and practiced somewhat separately in the earlier
TAs of this concept's own sequence — a learner who has correctly
mastered each test individually has no automatic reason to realize that
combining all three, rather than reporting whichever one or two feel
sufficient, is required for a genuinely unique identification.

## Misconceptions

The existing Blueprint (`docs/curriculum/blueprints/
eng.phonetics.consonant-sounds.md`, Component 1) documents both
misconceptions this concept produces, with full trigger/probe/bridge/
replacement/discrimination content — reused by reference below, with
birth-type classification added
(`../../misconceptions/01-birth-taxonomy.md`).

**MC-CLASSIFICATION-IS-JUST-LABELING (Blueprint Component 1) — Type 1,
overgeneralization**
- *Why (birth-type addition)*: the learner's prior experience (from
  the prerequisite concept) genuinely was a small, memorizable set of
  illustrative sound classifications — extending "I know these specific
  labels" into "I know the whole system" is a reasonable but incorrect
  generalization from a narrow domain (a few taught examples) into a
  broader one (any consonant, including untaught ones) where the
  narrower strategy silently fails.
- *Full trigger/probe/bridge/replacement/discrimination content*: see
  Blueprint Component 1, verbatim — not restated here.
- *Characteristic phrase (addition)*: a learner who, when presented
  with a genuinely novel sound, immediately begins narrating the three
  tests aloud ("let me check where it's made... now the airflow...")
  rather than searching memory for a label is showing the misconception
  has already resolved — this narrated, procedural approach is itself
  the strongest positive evidence of mastery, independent of whether
  the final classification happens to be correct.

**MC-PLACE-MANNER-VOICING-ARE-INDEPENDENT (Blueprint Component 1) —
Type 1, overgeneralization**
- *Why (birth-type addition)*: this concept's own earlier TAs (place,
  then manner, then voicing, taught across separate steps) reasonably
  reinforce a learner's sense that each dimension is a self-contained
  fact to be checked off — a structurally correct instructional
  SEQUENCE (teach one dimension at a time) is over-extended into an
  incorrect claim about the FINAL representation (that any one
  dimension, reported alone, constitutes a complete answer).
- *Full trigger/probe/bridge/replacement/discrimination content*: see
  Blueprint Component 1, verbatim — not restated here.
- *Characteristic phrase (addition)*: a learner who answers a full-
  classification question with only one or two dimensions and then, on
  being asked "does that fully identify the sound?", pauses and
  self-corrects by adding the missing dimension is showing productive,
  nearly-resolved understanding — a stronger state than a learner who
  needs the ambiguity explicitly demonstrated (the Blueprint's own
  conflict-evidence probe) before recognizing the gap.

## Analogies

- **Best analogy — height, width, and depth for fully specifying a
  box** (Blueprint's own analogy, Component 1's bridge text): three
  independent dimensions, none sufficient alone, all required together
  to uniquely specify the object — reused here directly as this
  concept's primary framing for the dimension-independence
  misconception, not restated as new content.
- **Alternative — a street address needing house number, street name,
  AND city, not any one alone**: reinforces that partial identification
  information, however correct as far as it goes, remains genuinely
  ambiguous without the remaining components. Breaking point: a street
  address has a natural, memorized WHOLE (most people know their full
  address as one unit), which might understate that the three phonetic
  dimensions are tested independently in this concept's own procedure,
  even though they must be REPORTED together.
- **ANTI-ANALOGY — do NOT frame classification as "matching the sound
  to its entry in a chart"**: a chart-lookup framing directly installs
  MC-CLASSIFICATION-IS-JUST-LABELING by presenting the system as a
  static reference table to be consulted rather than a live procedure
  to be run. If a learner asks "is there a chart I should memorize?",
  redirect explicitly: "the chart is something you could BUILD by
  running the tests yourself — the tests are the actual skill."

## Demonstrations

- **Physical/kinesthetic (three-test detective routine)**: the
  Blueprint's Component 3 anchor, applying place/manner/voicing tests
  in strict order to an unfamiliar-feeling sound — canonical,
  referenced not restated.
- **Home/no-equipment**: every test requires nothing beyond the
  learner's own mouth, face, and a hand on the throat; the full
  consonant inventory can be worked through anywhere.
- **Interactive/learner-activity**: TA-3's cognate-pair sorting and
  TA-5's novel-sound live classification are both hands-on, generative
  activities requiring the learner to test and report, not recall.
- **Teacher-demo (partial-vs-complete contrast)**: the tutor models
  stating only "voiceless" and "bilabial" for a sound, asking whether
  that fully identifies it, then adding "stop" to show the ambiguity
  resolve — directly instantiating the Blueprint's own conflict-
  evidence probe for dimension-independence.
- **Prediction to elicit FIRST, every time**: before confirming a
  classification (TA-1 through TA-4), ask the learner to predict from
  the felt tests before the tutor confirms — Universal Principle 3.

## Discovery Questions

**Direct instruction wins for the systematic inventory itself; a brief
discovery step suits the dimension-combination insight.** Working
through the full consonant set by place, then manner, then voicing
(TA-1 through TA-3) is systematic application of an already-taught
method to new material — there is no regularity to discover in WHICH
place category a given sound belongs to; it is simply tested and
recorded. The insight that all three dimensions must combine (TA-4),
however, suits a brief, argued discovery moment: **need** (the learner,
having separately mastered each test, is asked whether a partial
description like "voiceless bilabial" fully identifies a sound);
**playground/invention** (the learner tries adding manner and notices
the ambiguity resolves); **formalization** (MP-5's demonstrated three-
test narration, and the box/dimensions analogy stated explicitly);
**compression** (TA-4's fluent, unscaffolded three-dimension
description without needing to re-derive why all three are necessary
each time). This is a narrow, single-insight discovery step rather than
a full multi-stage arc.

## Teaching Sequence

TA-1 (place inventory) must precede TA-2 (manner inventory), which must
precede TA-3 (voicing across the full set), following the identical
easier-to-harder progression already established in the prerequisite
concept — place is the most concretely locatable dimension, manner the
next most abstract, voicing benefiting from being tested last since
cognate pairs (sharing place and manner) are most efficiently organized
once both prior dimensions are already known for each sound. TA-4
(full three-dimension classification) is placed after all three
individual inventories are complete, since it requires combining
dimensions that have each been separately systematized first. TA-5
(novel-sound classification) is placed last as the concept's genuine
mastery bar, requiring the full method to be applied without any
prior classification to fall back on — placing it earlier would test
the method before the full three-dimension vocabulary needed to
narrate it is available. This entry does not restate the Blueprint's
own turn-by-turn session script (Component 7) — see Blueprint
References below.

## Voice Teaching Notes

- **What to listen for**: whether the learner NARRATES the three-test
  procedure aloud when facing an unfamiliar sound (touching a spot,
  describing airflow, checking the throat) versus searching silently
  for a remembered label — this narrated, procedural behavior is the
  single strongest positive signal for resolving MC-CLASSIFICATION-IS-
  JUST-LABELING.
- **Characteristic hesitations**: a pause after stating one or two
  dimensions, followed by "wait, I need voicing too" (self-correction),
  is a strong positive sign of the dimension-combination insight taking
  hold; a fast, confident answer with only one dimension stated and no
  self-check is the concerning pattern.
- **Pronunciation stakes**: low for this concept's primary goal
  (describing sounds via place/manner/voicing), though per the
  prerequisite concept's own framing, L1-influenced productions remain
  a legitimate object of description and comparison (TA-5's optional
  L1-sound extension) rather than an error to correct.
- **The load-bearing sentence**: "run all three tests — where, how, and
  does it buzz" is this concept's load-bearing sentence, directly
  extending the prerequisite's single buzz-test emphasis into the full
  three-dimension procedure, per
  `../../foundations/03-voice-first-learning-model.md §3`.

## Assessment Signals

- **Diagnostic (golden probe)**: the Blueprint's own conflict-evidence
  probe (Component 1) — correctly classifying a previously-drilled
  sound, then being asked to classify a genuinely novel one using the
  same method — cleanly separates a learner relying on memorized labels
  from one who possesses the transferable method.
- **Guided practice → independent practice**: the Blueprint's WE-1 → WE-2
  → WE-3 → MP-1 through MP-5 fading ladder is reused directly
  (Components 5–6) — not re-authored here.
- **Mastery gate set** (`../../assessment/05-mastery-verification.md
  §3`): production (fresh place classification, MP-1); manner
  (MP-2); cognate-pair recall (MP-3, the voiced counterpart of a given
  voiceless sound — testing whether the pairing organization has been
  internalized); full-integration (MP-4, all three dimensions stated
  together for a fresh sound); genuine-novelty (MP-5, narrated live
  application to a sound not classified during the session — per the
  Blueprint's own explicit statement, this is the concept's actual
  mastery bar, and session design must include at least one truly
  novel sound before mastery is claimed).
- **Interpretation of response pattern**: fast-and-correct, narrated
  application of the three tests to a genuinely novel sound confirms
  the method (not merely a label set) is possessed. Fast-and-WRONG
  responses that skip straight to a guessed label without any test
  narration are the dangerous pattern for MC-CLASSIFICATION-IS-JUST-
  LABELING, warranting a return to TA-5's live-testing emphasis rather
  than more drilling on already-classified sounds. A response citing
  only one or two dimensions, however confidently stated, is
  incomplete regardless of speed and should route to TA-4's dimension-
  combination work.
- **Transfer items**: near (a fresh, previously-unclassified English
  consonant); far (a consonant from the learner's own L1, if
  applicable, classified using the identical three-test method — the
  strongest possible test that the framework is a general tool, not an
  English-specific list); real-world (classifying a sound from a name,
  word, or phrase encountered outside the lesson).

## Tutor Recovery Strategy

Concept-specific application of `../../foundations/01-recovery-engine.md`:
- **"I don't know"** on a classification task shrinks to re-running the
  three-test detective routine on the single most familiar sound from
  the prerequisite concept (typically /p/ or /m/), with the tutor
  modeling the full narrated procedure first, before returning to the
  target sound.
- **Likeliest utterance/behavior at this node**: a guessed label
  (rather than "I don't know") is more likely on a novel sound, per
  MC-CLASSIFICATION-IS-JUST-LABELING's mechanism — when a guess appears
  without any test narration, redirect explicitly to running the three
  tests live ("let's not guess — let's actually check") rather than
  confirming or denying the guess directly.
- **Non-verbal signal specific to this node**: a learner who physically
  touches their mouth/throat while thinking, before answering, is
  showing the correct testing behavior even when the eventual answer
  needs correction — this should be named and praised explicitly as
  exactly the target habit this concept builds.

## Memory Hooks

**Concept type**: procedure — a transferable diagnostic method (three
tests applied to any sound) rather than a fixed fact set, following a
skill-fluency pattern: correctness first (each test applied
accurately), then fluency in narrating and combining all three, with
particular ongoing emphasis on novel-sound application as the genuine
retention target, since a learner can appear to have mastered this
concept via memorization alone unless periodically re-tested on
material outside the original practice set. Interleaving partners: mix
familiar and genuinely novel sounds within ongoing review, and mix
questions asking for a single dimension with questions requiring the
full three-dimension description, so neither the "just recall a label"
shortcut nor the "report only one dimension" shortcut can silently
persist undetected.

## Transfer Connections

- **Near**: classifying fresh, previously-unclassified English
  consonants by place, manner, and voicing.
- **Far**: this concept's systematic classification transfers directly
  to `eng.phonetics.ipa-basics`, where IPA symbols are organized by
  exactly these same three dimensions, and to `eng.phonetics.vowel-
  sounds`' parallel (though structurally different) classification
  system for vowels.
- **Real-world**: any spoken consonant, in any language the learner
  encounters, is describable using this three-dimension framework — a
  genuinely universal linguistic tool, not an English-specific system.
- **Expert-transfer**: eventual formal phonetic transcription and
  cross-linguistic sound comparison, both well downstream, depend
  directly on this concept's classification system being fully secure
  and genuinely generalizable rather than memorized per-language.
