## Learning Objective

The learner can:
1. Revise an adjective-piled description into a precise, specific version using fewer but stronger words.
2. Expand a sight-only description to include at least two additional senses.
3. Convert a flat description using one figurative device (simile, metaphor, or personification).
4. Organize a set of unordered details using a stated spatial or impression-based strategy.
5. Compose a full multi-sensory description using precise language, multiple senses, and figurative language, deliberately organized.

## Core Understanding

Two corrections define this concept. First, **more adjectives do not always make description more vivid** — piling on near-synonym adjectives ("big, huge, enormous, gigantic") often dilutes vividness since redundant words all say roughly the same thing without adding new information, while a few precise, specific sensory details ("gnarled branches," "frost-covered") create a sharper, more vivid picture than a long list of vague size-words; quality and specificity beat quantity. Second, **descriptive writing is not limited to visual/sight details** — relying almost exclusively on sight (color, shape, size) neglects the other four senses, producing description that is visually complete but sensorially flat; genuinely immersive description draws on sound, smell, touch, and taste alongside sight, often carrying as much or more sensory power than visual detail alone.

## Mental Models

**Beginner — "more adjectives always makes description more vivid; descriptive writing only needs sight details."**
The simulation: stack multiple near-synonym adjectives for emphasis, and describe scenes purely by their visual appearance.
*Upgrade trigger*: the Blueprint's own conflict evidence — "big, tall, huge, enormous, gigantic, old, ancient tree" versus "the oak's gnarled branches cast long shadows across the frost-covered yard," asked which creates a clearer mental picture; and a sight-only bakery description versus a multi-sensory one, asked which feels more immersive.
*Shelf-life warning*: "Fewer, precise words beat a pile of redundant adjectives. Add senses beyond sight for real immersion."

**Intermediate — "I use precise language now, but I still tend to default mostly to sight when describing a scene."**
The simulation: correctly avoids adjective-piling but hasn't yet developed the habit of systematically checking for non-visual senses.
*Upgrade trigger*: TA-2's direct five-sense-check practice, adding details from at least two additional senses to a sight-only description.
*Shelf-life warning*: "Before finishing, check: have you used only sight? Add sound, smell, touch, or taste."

**Advanced — "I choose precise words over adjective piles, draw on multiple senses, apply figurative language, organize details deliberately, and compose a full multi-sensory description."**
The simulation: integrates precision, multi-sensory detail, figurative language, and deliberate organization into one coherent, generative composition. Matches TA-5.
*Upgrade trigger*: the cross-linked `eng.writing.creative-writing-forms`, extending multi-sensory precision to a wider range of creative genres.
*Shelf-life warning*: "This gives you the full descriptive toolkit. Creative writing forms extends this precision to other genres."

**Expert — "at fluency, precise word choice and multi-sensory awareness happen as an integrated part of ordinary descriptive drafting."**
Named to mark the arc; the explicit precision-check and five-sense-check routine is a scaffold for a compositional judgment that, at true fluency, operates as an integrated part of drafting.

## Why Students Fail

The dominant mechanism is that **adding more words feels like adding more effort and therefore more quality**, a natural but incorrect proxy — piling on adjectives feels like "trying harder" to describe something vividly, when the actual vividness comes from precision, not volume, the same mechanism identified for detail selection in `eng.writing.supporting-details`.

The second mechanism is that **sight is the dominant sense in most people's default mental representation of a scene**, and early descriptive-writing instruction often emphasizes visual imagery first and most heavily, so the habit of describing primarily what something LOOKS like becomes the unexamined default, with the other senses requiring a deliberate, separate prompt to activate.

## Misconceptions

The Blueprint's **Component 1 — Misconception Register** owns trigger signals, conflict evidence, bridge/replacement text, and discrimination pairs for both entries below. Reused by reference; birth-type classification and teaching consequence added here.

### MC-MORE-ADJECTIVES-ALWAYS-MAKES-DESCRIPTION-MORE-VIVID
*(Blueprint Component 1, first entry — the adjective-pile/precise-sensory discrimination pair.)*
- **Birth type**: Type 2 (perceptual intuition), from word-count feeling like a proxy for descriptive effort and quality, mistaken for actual vividness, which depends on precision rather than volume — the identical mechanism identified for quantity-as-strength in `eng.writing.supporting-details`.
- **Teaching consequence**: the repair requires **direct comparison of an adjective-piled description against a precise, sensory-specific one**, since the counterintuitive claim (fewer words, clearer image) is more convincing demonstrated than asserted.
- **Verification of death**: given an adjective-piled description, the learner revises it into a precise, specific version using fewer but stronger words.

### MC-DESCRIPTIVE-WRITING-ONLY-USES-VISUAL-SIGHT-DETAILS
*(Blueprint Component 1, second entry — the sight-only/multi-sensory discrimination pair.)*
- **Birth type**: Type 5 (instruction-induced), from sight's dominant role in early descriptive-writing instruction and default mental imagery, leaving the other four senses unexamined as equally valid tools.
- **Teaching consequence**: the repair requires **a mandatory five-sense checklist**, since the fix requires a deliberate, structured prompt to activate senses that don't arise spontaneously, not merely being told other senses exist.
- **Verification of death**: given a sight-only description, the learner adds details from at least two additional senses.

## Analogies

**Best — the Five-Sense Dial and the Precision Filter** (Blueprint Component 3): a physical dial with five sense positions, rotated through systematically rather than settling only on Sight, directly seeds the multi-sensory fix; a funnel that only lets one precise word through at a time from a jumbled pile of synonym adjectives, paired with a concrete sensory detail, directly seeds the precision fix.
*Breaking point*: a physical dial has discrete, equally-weighted positions, while in real description some senses (sight, sound) are often more naturally dominant for a given scene than others (taste) — useful for the systematic-rotation-through-all-senses intuition, less precise for implying every sense deserves exactly equal representation in every passage.

**Alternative — a sommelier's tasting notes versus a wine label's bare facts.** A wine label states bare facts (grape, region, year); a sommelier's tasting notes describe aroma, texture, and flavor in specific, sensory language — the same underlying subject, but one is flat information and the other is vivid, multi-sensory description.
*Breaking point*: a sommelier's vocabulary is highly specialized and trained, while ordinary descriptive writing draws on more universally accessible sensory vocabulary — useful for the specific-sensory-language intuition, less precise for implying comparable specialized expertise is required.

**Visual anchor — the Five-Sense Dial and the Precision Filter**, as the primary teaching metaphor and working instrument.

### ANTI-ANALOGIES (do not use)

- **"The more descriptive words you use, the more vivid your writing will be."** Directly installs the adjective-piling misconception as a stated rule.
- **"Just describe what something looks like — that's descriptive writing."** Directly installs the sight-only misconception as a stated definition.

## Demonstrations

Prediction first in every case.

1. **The Five-Sense Dial and the Precision Filter (learner activity).** Blueprint Component 3 — full script there. *Predict first*: "If you only use the Sight position on the dial, are you missing something?" Then rotate through all five positions; separately, funnel the adjective pile down to one precise word.
2. **The adjective-pile/precise-sensory collision (teacher-led, learner-resolved).** Blueprint's own conflict evidence for the first misconception. *Predict first*: "Which one creates a clearer mental picture?"
3. **The sight-only/multi-sensory collision (teacher-led, learner-resolved).** Blueprint's own conflict evidence for the second misconception. *Predict first*: "Which one makes you feel more immersed in the scene?"

## Discovery Questions

Well suited to **guided discovery**, since both descriptive facts are directly checkable by comparing paired descriptions for precision and sensory range.

1. **Need**: "If you use five adjectives that all mean roughly the same thing, does that actually help the reader picture something more clearly?"
2. **Playground**: the learner writes several sensory details for one scene freely, testing different senses, before being told the official five-sense checklist.
3. **Invention**: "Can you describe this scene using only ONE precise word per sense, and still make it vivid?"
4. **Collision**: present a sight-only bakery description and a multi-sensory one; ask which feels more immersive.
5. **Formalization**: name the two descriptive facts — precision beats quantity; multiple senses beat sight alone — from the learner's own testing.
6. **Compression**: "Fewer, sharper words — and more than just sight."

## Teaching Sequence

- **Precision vs. quantity sorting (TA-1) comes first**, directly confronting the adjective-piling misconception before figurative language or organization is introduced.
- **The five-sense check (TA-2) comes second**, directly confronting the sight-only misconception once precision is established.
- **Figurative language for precision (TA-3) comes third**, adding a further precision tool once the basic word-choice discipline is secure.
- **Organizing a description (TA-4) and composing a full multi-sensory description (TA-5) come last**, adding structural organization and integrating everything into a generative capstone — matching this program's established sequencing principle.

## Voice Teaching Notes

Core evidence is **the learner's stated reasoning for a word choice or a sensory addition**, since a technically-complete description with no stated precision or sensory-range reasoning cannot be distinguished from surface compliance.

What the ideal tutor perceives:

- **A stated precision check** ("do I need all these size words, or is one specific detail sharper?") applied to a drafted description — the direct behavioral signature of the precision fix taking hold.
- **Voluntary addition of a non-visual sensory detail** without being prompted for that specific sense — direct evidence the multi-sensory fix is internalized.
- **A description with multiple redundant adjectives, or a passage relying exclusively on visual detail** — the direct behavioral signature of either misconception still active.

**Load-bearing sentence, delivered slowly**: *"Choose fewer, sharper words — and reach beyond sight for what you're describing."*

## Tutor Recovery Strategy

Generic engine: `../foundations/01-recovery-engine.md`. Concept-specific notes only:

- **"I added lots of describing words, isn't that more vivid?"** — take this as a reasonable, effort-signaling instinct; respond by naming the actual effect: "Let's check — do all these words say something different, or are some of them repeating the same idea? One sharp word can beat five similar ones."
- **"I described what it looks like, isn't that descriptive writing?"** — a reasonable default given sight's dominant role; respond by widening the lens: "That's a great start — now what does it sound like, smell like, or feel like?"
- **Smaller question to shrink to**: from a full multi-sensory composition down to **revising a single adjective-piled phrase into one precise sensory detail, with no five-sense-expansion or organization task demanded.** Isolates the most basic precision skill before returning to fuller composition.
- **Never shrink to "just add a few more descriptive words."** This directly licenses the adjective-piling pattern, undermining the precision discipline this concept specifically builds.
