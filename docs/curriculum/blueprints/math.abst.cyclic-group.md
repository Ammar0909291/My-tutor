## Component 1: Cognitive Map

### Target Understanding
A **cyclic group** is a group G that is generated by a single element: G = ⟨g⟩ = {gⁿ : n ∈ ℤ}.
Every element of G is some power (or multiple) of the generator g.

**Key facts:**
- Every cyclic group is **abelian** (since gⁿ · gᵐ = gⁿ⁺ᵐ = gᵐ · gⁿ — exponents commute).
- Every subgroup of a cyclic group is cyclic.
- **Finite cyclic groups:** G = ⟨g⟩ with |G| = n is isomorphic to Z/nZ.  The generator g has order n.
- **Infinite cyclic group:** ⟨g⟩ = {…, g⁻², g⁻¹, e, g, g², …} ≅ (ℤ, +).
- **Order of an element:** The smallest positive integer k such that gᵏ = e.
  If no such k exists (infinite group), the element has infinite order.

### Distinction from math.abst.group-theory
`math.abst.group-theory` established the four axioms.  This blueprint introduces **generation**:
a group may be completely described by repeated application of one element and its inverse.
The classification theorem (finite cyclic ≅ Z/nZ; infinite cyclic ≅ ℤ) is the key theorem.

### Conceptual Layers (C → P → A)
| Layer | Content |
|-------|---------|
| **Concrete (C)** | Z/6Z: powers of 1 give {0,1,2,3,4,5} = all of Z/6Z; g=1 is a generator |

### TA-A01 · Z/6Z: Prototype Cyclic Group (P11 + P49)

**[P11 — REPRESENTATION SHIFT]**

Four representations of "Z/6Z is generated by 1":

| Representation | G = ⟨1⟩ in Z/6Z |
|----------------|-----------------|
| **Verbal** | "Starting from 0, add 1 repeatedly mod 6; you visit every element exactly once before returning to 0" |
| **Symbolic** | ⟨1⟩ = {1·0, 1·1, 1·2, 1·3, 1·4, 1·5} = {0, 1, 2, 3, 4, 5} = Z/6Z |
| **Clock** | 6-hour clock: 0→1→2→3→4→5→0; after 6 steps, back to start |
| **Order** | Order of 1 = smallest k with k·1 ≡ 0 (mod 6) = 6 |

**Orders of all elements in Z/6Z:**
| Element a | Smallest k: k·a ≡ 0 (mod 6) | Order | Generates |
|-----------|------------------------------|-------|-----------|
| 0 | 1 | 1 | {0} (trivial subgroup) |
| 1 | 6 | 6 | {0,1,2,3,4,5} = Z/6Z ✓ generator |
| 2 | 3 | 3 | {0,2,4} |
| 3 | 2 | 2 | {0,3} |
| 4 | 3 | 3 | {0,2,4} |
| 5 | 6 | 6 | {0,1,2,3,4,5} = Z/6Z ✓ generator |

Generators of Z/6Z: elements of order 6 = {1, 5}.

**[P49 — ADAPTIVE CHECKPOINT]**

> In Z/6Z: (i) What is the order of 4?  (ii) Does 4 generate all of Z/6Z?  What does it generate?

Expected:
*(i) Smallest k: k·4 ≡ 0 (mod 6). 1·4=4; 2·4=8≡2; 3·4=12≡0. Order of 4 = 3.*
*(ii) No. ⟨4⟩ = {0, 4, 2} = {0, 2, 4}. Only generates 3 elements, not all 6.*

- **CORRECT** (order 3; generates {0,2,4}): ✓ Advance to TA-A02.
- **PARTIAL — order wrong**: Walk through 4, 8≡2, 12≡0. Return.

- **NO_RESPONSE**: Scaffold "Compute 4 mod 6, then 2·4 mod 6, then 3·4 mod 6. Which is the first to give 0?"

### TA-A02 · Pattern Gallery: Generators vs Non-Generators (P04 + P49)

**[P04 — PATTERN INDUCTION]**

Pattern across four cyclic groups — which elements generate the whole group?

| Group | All elements | Generators (order = |G|) | Non-generators |
|-------|-------------|--------------------------|----------------|
| Z/4Z | {0,1,2,3} | {1, 3} | 0 (order 1), 2 (order 2) |
| Z/5Z | {0,1,2,3,4} | {1,2,3,4} | 0 (order 1) |
| Z/6Z | {0,1,2,3,4,5} | {1, 5} | 0,2,3,4 |
| Z/8Z | {0,…,7} | {1,3,5,7} | 0,2,4,6 |

**Pattern:** The generators of Z/nZ are exactly the elements **coprime to n** (i.e., gcd(a, n) = 1).
- Z/5Z: all non-zero elements are coprime to 5 (prime) → all 4 non-zero elements are generators.
- Z/6Z: gcd(1,6)=1 ✓; gcd(2,6)=2 ✗; gcd(3,6)=3 ✗; gcd(4,6)=2 ✗; gcd(5,6)=1 ✓.

**Key insight:** A cyclic group has a generator — but not every element IS a generator.
(MC-2 target: only elements with gcd(a,n)=1 are generators.)

**[P49 — ADAPTIVE CHECKPOINT]**

> (i) How many generators does Z/12Z have?
> (ii) Is (ℤ, +) cyclic?  What is/are its generators?

Expected:
*(i) Elements coprime to 12: φ(12) = 12·(1−1/2)·(1−1/3) = 4. Elements: {1,5,7,11}. 4 generators.*
*(ii) Yes. ℤ = ⟨1⟩ = ⟨−1⟩. Adding 1 repeatedly gives all positive integers; adding −1 gives all negatives. Two generators.*

- **CORRECT** (4 generators; ℤ is cyclic with generators ±1): ✓ Advance to TA-A03.
- **PARTIAL — (ii) says ℤ is not cyclic**: MC-1 active. Route TB-R01 now. Return.
- **PARTIAL — (i) wrong count**: Recount elements with gcd(a,12)=1. Re-administer.
- **NO_RESPONSE**: Scaffold "(i) gcd(1,12)=?, gcd(2,12)=?, gcd(3,12)=?, count how many give 1."

### TA-A03 · Cyclic vs Non-Cyclic; Cyclic Implies Abelian (P06 + P49)

**[P06 — CONTRAST PAIR]**

**Cyclic — Z/6Z:**
- G = ⟨1⟩: single generator produces all 6 elements.
- All elements are powers (multiples) of 1.
- Cayley table is symmetric (abelian).
- Proof cyclic ⟹ abelian: any two elements are gⁿ and gᵐ for some n, m.
  gⁿ · gᵐ = gⁿ⁺ᵐ = gᵐ⁺ⁿ = gᵐ · gⁿ (integer addition is commutative → cyclic groups are abelian). ✓

**Non-Cyclic — Klein four-group V₄ = Z/2Z × Z/2Z:**
- Elements: {e, a, b, c} with a² = b² = c² = e and ab = c, bc = a, ca = b.
- Max order of any element = 2.  No element generates all 4 elements (need order 4 for that).
- V₄ is NOT cyclic.  (But it IS abelian — non-cyclic abelian groups exist.)
- The converse "abelian ⟹ cyclic" is FALSE: V₄ is abelian but not cyclic.

**Summary:**
- Cyclic ⟹ abelian.  (Always true.)
- Abelian ⟹ cyclic.  (FALSE — V₄ is a counterexample.)

**[P49 — ADAPTIVE CHECKPOINT]**

> True or False?  Justify with a proof or counterexample:
> (i) Every cyclic group is abelian.
> (ii) Every abelian group is cyclic.

Expected:
*(i) TRUE.  Proof: let G = ⟨g⟩.  Any two elements are gⁿ, gᵐ.  gⁿ·gᵐ = gⁿ⁺ᵐ = gᵐ·gⁿ. ✓*
*(ii) FALSE.  Counterexample: V₄ = Z/2Z × Z/2Z is abelian but has no element of order 4 → not cyclic.*

- **CORRECT** (both with justification): ✓ Advance to TA-A04.
- **PARTIAL — (i) true but no proof**: Ask "Why? Write gⁿ·gᵐ in terms of the generator." Return.
- **PARTIAL — (ii) claims true**: MC-3 partially. Show V₄ has no element of order 4. Return.
- **INCORRECT**: Route TB-R03 (cyclic ⟹ abelian proof) and TB-R01 (V₄ counterexample). Return.
- **NO_RESPONSE**: Scaffold "(i) Write two arbitrary elements of G = ⟨g⟩ as powers of g, then compute their product both ways."

**[P77 — MULTI-PROBLEM SET]**  (4 questions)

**Q1.** Prove that every cyclic group is abelian.
*(Let G = ⟨g⟩.  Take any a, b ∈ G; then a = gⁿ, b = gᵐ for integers n, m.
 a·b = gⁿ·gᵐ = gⁿ⁺ᵐ = gᵐ⁺ⁿ = gᵐ·gⁿ = b·a.  Since a, b were arbitrary, G is abelian. ✓)*

**Q2.** Find all generators of Z/8Z and explain why they are generators.
*(Generators = elements coprime to 8 = {1, 3, 5, 7}.  Coprime means gcd(a,8)=1.  Each has order 8,
 generating all of Z/8Z.  Non-generators: 0 (order 1), 2 (order 4), 4 (order 2), 6 (order 4).)*

**Q3.** Is the group D₃ (dihedral group of the triangle, 6 elements) cyclic?  Justify.
*(No.  D₃ is non-abelian (sr ≠ rs).  Every cyclic group is abelian.  Contrapositive: non-abelian ⟹ not cyclic.  D₃ is not cyclic.  Alternatively: no single element generates all 6 elements (r has order 3, s has order 2; neither generates all of D₃).)*

**Q4.** What is ⟨4⟩ in Z/10Z?  What is the order of 4 in Z/10Z?
*(4·1=4, 4·2=8, 4·3=12≡2, 4·4=6, 4·5=10≡0.  Order = 5.  ⟨4⟩ = {0, 4, 8, 2, 6} — 5 elements (a subgroup of Z/10Z).)*

**[P55 — SCORE]**  Tally Q1–Q4.

**[P76 — TRANSFER PROBE]**  (P76_MODE = Independence)

*Independence probe: applies cyclic group concept to nth roots of unity in ℂ.*

> The nth roots of unity are the complex numbers ωₖ = e^(2πik/n) for k = 0, 1, …, n−1.
> These form a group under complex multiplication.
>
> (i) Show that the set Cₙ = {ω₀, ω₁, …, ωₙ₋₁} is closed under multiplication.
> (ii) What is the identity element?  What is the inverse of ωₖ?
> (iii) Show that Cₙ = ⟨ω₁⟩, i.e., Cₙ is cyclic with generator ω₁ = e^(2πi/n).
> (iv) What group is Cₙ isomorphic to?

*Expected answers:*
- **(i)** ωⱼ · ωₖ = e^(2πij/n) · e^(2πik/n) = e^(2πi(j+k)/n) = ω_{(j+k) mod n} ∈ Cₙ. ✓
- **(ii)** Identity: ω₀ = e^0 = 1. Inverse: ωₖ⁻¹ = ω_{n−k} (since ωₖ · ω_{n−k} = ω_{(k+n−k) mod n} = ω₀ = 1).
- **(iii)** ω₁ᵏ = e^(2πik/n) = ωₖ for k = 0,1,…,n−1. So ⟨ω₁⟩ = {ω₀,…,ωₙ₋₁} = Cₙ. ✓
- **(iv)** Cₙ ≅ Z/nZ (both are cyclic groups of order n; the map k ↦ ωₖ is an isomorphism).

**[P55 — SCORE]**  Award 1 point for P76 if (iii) and (iv) correct; 0 otherwise.

## Component 5: Protocol B — Repair Chains

---

### TB-R01 · Repair: CYCLIC-MEANS-FINITE (MC-1)

**Trigger:** Student claims cyclic groups must be finite.

**Step 1 — Apply the definition.**
> G = ⟨g⟩ means: every element of G is gⁿ for some integer n ∈ ℤ (including negative integers — those give g⁻¹, g⁻², …).  Nothing in the definition requires finiteness.

**Step 2 — Concrete infinite cyclic example.**
> (ℤ, +) with generator 1: every integer n = 1 + 1 + … (n times) or −1 − 1 − … (|n| times).
> So ℤ = ⟨1⟩.  Infinitely many elements, yet cyclic.

**Step 3 — Classification theorem.**
> Finite cyclic group of order n ≅ Z/nZ.
> Infinite cyclic group ≅ (ℤ, +).
> Both exist; the definition covers both.

**Exit:** Return to TA-A02 P49 checkpoint, part (ii).

---

### TB-R02 · Repair: EVERY-ELEMENT-IS-A-GENERATOR (MC-2)

**Trigger:** Student says every element of a cyclic group generates the whole group.

**Step 1 — Counter-compute in Z/6Z.**
> ⟨2⟩: 2, 4, 0 — only 3 elements.  Does not generate Z/6Z.
> ⟨3⟩: 3, 0 — only 2 elements.  Does not generate Z/6Z.

**Step 2 — State the correct criterion.**
> Generator of Z/nZ ↔ element a with gcd(a, n) = 1.
> gcd(2, 6) = 2 ≠ 1 → 2 is NOT a generator.
> gcd(1, 6) = 1 → 1 IS a generator.

**Step 3 — Verify 1 is a generator but 2 is not.**
> ⟨1⟩: 1,2,3,4,5,0 — all of Z/6Z ✓.
> ⟨2⟩: 2,4,0 — only 3 elements ✗.

**Exit:** Return to TA-A02 P49 checkpoint, part (i).

---

### TB-R03 · Repair: CYCLIC-IMPLIES-NONABELIAN-POSSIBLE (MC-3)

**Trigger:** Student thinks some cyclic groups might be non-abelian.

**Step 1 — Proof that cyclic ⟹ abelian.**
> Let G = ⟨g⟩ (cyclic).  Pick any two elements: a = gⁿ, b = gᵐ.
> a · b = gⁿ · gᵐ = gⁿ⁺ᵐ (power law, follows from G2 applied repeatedly).
> b · a = gᵐ · gⁿ = gᵐ⁺ⁿ.
> n + m = m + n (integers are commutative) → gⁿ⁺ᵐ = gᵐ⁺ⁿ.
> So a · b = b · a for ALL a, b ∈ G.  G is abelian.

**Step 2 — Contrapositive.**
> If G is non-abelian ⟹ G is NOT cyclic.  (e.g., D₃ is non-abelian, hence not cyclic.)

**Exit:** Return to TA-A03 P49 checkpoint.

<!-- COMPONENT 8: TEACHING NOTES -->
## Component 8: Teaching Notes

**1. Z/6Z as the richer prototype (vs Z/4Z or Z/5Z).**
Z/6Z has both generator and non-generator elements (unlike Z/5Z where all non-zero elements are
generators, or Z/4Z which is less interesting).  Using Z/6Z in TA-A01 ensures students see both
types immediately.

**2. The ⟨g⟩ notation for negative powers.**
When G = ⟨g⟩ is infinite, negative exponents (g⁻¹, g⁻², …) are needed.  In TA-A02, the
(ℤ,+) example uses −1 as the additive analogue of g⁻¹.  Make this explicit so the student
understands "powers" includes negative integers.

**3. The gcd criterion is a pattern, not a theorem to prove.**
At bloom=understand, the gcd criterion for generators is observed from the gallery in TA-A02
and verified on Z/12Z — not formally proved.  The proof (Euler's φ-function argument) lives in
math.nt territory.  Present it as the empirical pattern.

**4. MC-1 (cyclic means finite) is the dominant error.**
Students confuse "cycle" (finite return to start) with "cyclic group."  The (ℤ,+) example in
TB-R01 is the cleanest counterexample.  Some students will not encounter it until TA-A02 P49
part (ii) — route immediately to TB-R01 on failure.

**5. The P76 roots of unity probe is conceptually rich but computationally light.**
Parts (i)–(iii) follow directly from the definition of complex multiplication and the
definition of cyclic group.  Part (iv) requires recognising the isomorphism Z/nZ ≅ Cₙ without
formally proving it — "same structure, same group, different notation" suffices at this level.
