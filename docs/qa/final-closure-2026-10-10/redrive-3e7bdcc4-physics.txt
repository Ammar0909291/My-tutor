**Lesson: SI Units and Measurement**  
In this lesson we’ll explore the International System of Units (SI) that scientists use to describe everything from the length of a table to the mass of a car. By the end, you’ll be able to name all seven SI base units and know how to use them correctly.

Let’s start with the first base unit—**the metre**, which measures length. Imagine a simple wooden ruler you might keep on a desk; its evenly spaced marks let you see how long an object is. Picture holding that ruler next to a notebook and counting the marks from one end to the other to see how many metres (or fractions of a metre) the notebook spans. In everyday language we say the ruler “measures length,” and the official SI name for that measurement is the **metre (m)**.

[learner] give me example
[tutor provider=groq fig=none card=none flags=-]
Here’s a concrete step‑by‑step conversion that uses the unit we see for length in the figure:

**Convert 250 centimetres to metres**

1. Write the quantity with its unit: **250 cm**. 
2. Attach the conversion factor that links centimetres to metres:

\( \displaystyle 250\ \text{cm} \times \frac{1\ \text{m}}{100\ \text{cm}} \)

(One metre equals one‑hundred centimetres, so we multiply by “one metre over one‑hundred centimetres”.) 
3. Cancel the centimetre units: the “cm” in the numerator and denominator disappear, leaving only metres. 
4. Perform the arithmetic: \( 250 \div 100 = 2.5 \).

Result: **250 cm = 2.5 m**.

You can see how the units behave like algebraic symbols, cancelling where they match and leaving the desired unit at the end.

[tutor provider=memory fig=none card=none flags=-]
A table described as just "two" long tells nobody anything. Two metres is a table; two centimetres is a toy. The number alone carries no information — it only means something once the size being counted is named. That is what a unit is: an agreed size that everyone measures against. Scientists agree on a small set of these so that a result measured in one place means the same in another. Without the unit, the number stops being a measurement.
