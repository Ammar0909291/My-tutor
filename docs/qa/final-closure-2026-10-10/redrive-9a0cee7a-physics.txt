**Lesson: SI Units and Measurement**  

In this lesson we’ll explore the International System of Units (SI) that scientists use to describe everything they measure. By the end, you’ll be able to name the seven SI base units and know when to use each one.

Let’s start with the very first base unit: **length**.

Imagine a simple **ruler** you might keep on your desk.  
When you need to know how long your notebook is, you place the ruler along the edge of the notebook and read the markings.  

Think of the ruler as a “yardstick” that stretches straight from one end of the notebook to the other, giving you a clear picture of how far apart the two ends are.

In everyday language, we say the ruler measures the **length** of an object. In the SI system, the official unit for length is the **metre**, symbol **m**. One metre is defined as the distance light travels in a vacuum in 1⁄299 792 458 seconds.  

*Vocabulary:* **base unit** – a fundamental unit from which all other units are derived.

**Question:** Looking at the ruler placed on your notebook, what do you notice about the markings that help you determine the notebook’s length?

[learner] give me example
[tutor provider=groq fig=none card=none flags=moneyAsMath]
Let’s see how a speed measured in kilometres per hour (km / h) is turned into the SI base unit for length (metre) per the SI base unit for time (second).

**Example:** Convert 90 km / h to metres / second. 
1. Write the number with its original units: 90 km / h. 
2. Multiply by a factor that changes kilometres to metres, using the fact that 1 km = 1000 m:

\(90 \text{km / h} \times \frac{1000 \text{m}}{1 \text{km}}\).

The “km” units cancel, leaving 90 × 1000 m / h. 
3. Multiply by a factor that changes hours to seconds, using 1 h = 3600 s:

\(90 × 1000 \text{m / h} \times \frac{1 \text{h}}{3600 \text{s}}\).

The “h” units cancel, leaving metres per second. 
4. Do the arithmetic:

\(90 × 1000 ÷ 3600 = 25\) m / s (approximately).

So 90 km / h ≈ 25 m / s, which uses only the SI base units **metre** (length) and **second** (time) shown in the figure.

Fahrenheit is a common temperature scale, but it is not part of the International System of Units. The SI base unit for temperature is the kelvin, not degrees Fahrenheit. Using Fahrenheit does not satisfy the SI definition.

The kelvin is an absolute scale that starts at absolute zero, the point where molecular motion stops. It is defined by fixing the value of the Boltzmann constant, making it independent of any particular substance. This ensures consistency in scientific measurements worldwide.
