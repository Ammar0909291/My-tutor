**Lesson: Square Roots**  

In this lesson we’ll discover what a *square root* is – the number that, when multiplied by itself, gives the original value – and later we’ll see how this idea extends to other kinds of roots. By the end you’ll be able to identify a square root, write it using the √ symbol, and find simple square‑root values.

Imagine you have a square‑shaped chocolate bar that is 9 square pieces in total.  
In a real kitchen you might want to break the bar into equal rows and columns so it looks like a perfect square again.  

Picture the bar arranged in a perfect square shape: each side has the same number of pieces, and the total number of pieces is the side length multiplied by itself.

What do you notice about the length of each side when the total number of pieces is 9?

Here’s the next piece of the lesson.

When the radicand (the number under the root sign) is negative, the **type of root matters**. 

- For a square root, the radicand must be non‑negative. So \(\sqrt{-9}\) has no real value; we say it is *undefined* in the real numbers. - For a cube root, the radicand can be any real number because an odd power keeps the sign. The cube root of \(-8\) is \(-2\) because \((-2)^3 = -8\). 

Notice how the result of the cube root is a single, well‑defined number, while the square root simply does not exist in the real number system.

Taking a square root undoes squaring: √49 = 7 because 7² = 49. If squaring asks "how many counters in this square?", the root asks "how long is the side?".

Both 7 and −7 square to 49, so the equation x² = 49 has two solutions. The symbol √ is defined to give only the non-negative one, which is why √49 is 7 and not ±7 — the plus-or-minus in "x = ±7" is written in deliberately, because the symbol alone will not supply it.

Most roots are not whole numbers, and trapping them between two squares is the honest way to handle it: 49 < 60 < 64, so √60 is between 7 and 8, and nearer 8 because 60 is nearer 64. Answering "about 7.7" is a real answer, not a failure to find the exact one.

Think of the graph as a map that tells you the length of a square’s side when you know the square’s area. 
If you have a piece of land that covers 9 square meters, the side of a square that fits exactly on that land is 3 metres, because 3 × 3 = 9. So every point on the curve follows the rule “side = √area”.
